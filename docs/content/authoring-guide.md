# Kindy 콘텐츠 Authoring 가이드 (전문가 섭외·온보딩용)

> 이 문서 하나로 유아교육 전문가·아동 콘텐츠 작가·애니메이터·성우가 Kindy 콘텐츠를 만들 수 있게 한다.
> 제작 모델: **전문가가 토대(세계관·스토리·학습설계·아트·음성)를 authored** → **시스템이 아이별로 개인화**. 완전 AI 생성 아님.
> 레퍼런스 예시: `docs/content/animal-village-season1.md` + `src/data/worlds/animal-village.ts`.

---

## 0. 제품 한눈에
- **무엇**: 만 3–9세 아이가 **15–20분** 즐기며 **정서(마음)+창의(생각하는 힘)**를 한 이야기 안에서 키우는 웹/아이패드(가로) 프로그램.
- **어떻게 팔리나(포지셔닝)**: 부모에겐 **"AI 시대 미래역량 — 사고력·문해력·표현력·자기주도"**로. ⚠️ **"정서 교육"·"창의성 교육"이라는 단어를 부모 대면에 쓰지 않는다.** 내부 설계 용어로만.
- **세션 한 판 = 2막**: ①영상/도입(정서 사건) → 정서 활동 → ②전환 → 창의 활동 → 클로저. 한 시즌(4–6주) 끝 = 아이가 풀어낸 **"나만의 이야기책"**.
- **학습 근간**: 정서=CASEL 5역량 / 창의=호서대 「창의적 사고와 디자인」 = 「생각의 탄생」 13 생각도구(관찰·형상화·추상화·패턴·유추·**감정이입**·통합 등) + 디자인(도형·패턴·색·콜라주).

---

## 1. 무엇을 전문가가 만들고, 무엇을 시스템이 하나
| | 전문가가 **authored(고정)** | 시스템이 **개인화/자동** |
|---|---|---|
| 세계관·캐릭터 | ✅ 설계·디자인 | 아이가 좋아할 세계/캐릭터 **선택·추천** |
| 시즌 스토리·사건 | ✅ 아크·분기 작성 | 아이 선택에 따라 **경로 분기**(사전제작 범위 내) |
| 활동 내용·문구·정답 | ✅ 템플릿에 채움 | 난이도·반복·순서 **적응(DDA)** |
| 학습목표 정렬 | ✅ 활동↔목표 매핑 | 진도·취약 영역 **추적** |
| 아트·애니메이션 | ✅ 캐릭터·자산·동작 | 조합·재생 |
| 음성 | ✅ 성우 녹음(or 디렉션) | 재생·자막 |
→ **전문가는 "레시피와 재료"를 만들고, 시스템은 아이마다 다르게 "차려낸다."**

## 2. Authoring 스키마 (채워야 할 것)
`src/data/worlds/<world>.ts` 한 파일이 한 세계. 구조:

### 2.1 세계(World)
- `id`, `name`(예: 동물 마을), `tagline`(한 줄 분위기)
- `seasonArc`: 시즌 전체 이야기(열린 결말). "무엇을 향해 가는가"(예: 별빛 축제를 함께 완성).
- `artStyle`: 아트 톤(색감·질감·연령감) — 애니메이터용.

### 2.2 캐릭터(Character) — 반복 출연이 애착을 만든다
- `id`, `name`, `appearance`(외형/이모지 placeholder), `personality`(한 줄 성격)
- `emotionTheme`: 이 캐릭터가 대표하는 정서(예: 꾸미=슬픔·위로 / 방울=기쁨·자기조절)
- `role`: 가이드(마스코트)·주인공 친구·내레이터
- `voice`: 음성 캐릭터(성우 디렉션 — 톤·나이감·말투). 예: "힘없고 여린 8살 톤".

### 2.3 세션(Session) = 2막
- `intro`: 도입 내레이션(누가·무슨 사건). 영상 또는 캐릭터 카드.
- `emotionAct`: 정서 활동 2–3개(사건의 감정을 알아채고·공감하고·해결 실마리)
- `transition`: 정서→창의 다리 대사("이제 나만의 방법으로 도와줄까?")
- `creativityAct`: 창의 활동 2–3개(나만의 방법으로 해결·창작)
- `closing`: 결말 + 보상 + "나만의 이야기책" 한 장 + 부모 대화 스타터.

### 2.4 활동(Activity) — 8 템플릿 중 선택해 채움
각 활동 공통 필드:
- `template`: 아래 8종 중 하나
- `dimension`: `emotion`(정서) 또는 `creativity`(창의)
- `objective`: 학습목표 코드(정서=CASEL / 창의=교수 6도구; §4 참조)
- `prompt`: 아이에게 줄 한국어 안내문(쉽고 짧게)
- `voiceLines`: 음성으로 읽을 대사(안내·정답 칭찬·오답 격려·힌트) — 성우/ TTS용
- `assets`: 활동에 쓰는 항목들(이모지/이미지 + 라벨)
- `feedback`: 정답/오답/힌트 문구
- `hasCorrectAnswer`: 창작 활동은 `false`(= 정답 없음, **참여도**로 평가)
- `difficultyParams`: 항목 수·시간 등(시스템이 연령·실력에 맞춰 조절)

## 3. 활동 템플릿 8종 (이미 구현됨 — 여기에 콘텐츠만 채우면 됨)
| 템플릿 | 차원 | 아이가 하는 것 | 자산 형식 |
|---|---|---|---|
| 표정 읽기 | 정서 | 캐릭터 표정 보고 감정 고르기 | 표정 4종 + 감정 라벨 |
| 마음 헤아리기 | 정서 | "왜 그런 마음일까?" 이유 고르기 | 상황 + 이유 선택지 |
| 숨은 친구 찾기 | 정서/창의 | 배경에서 숨은 친구 탭 | 배경 + 숨은 항목 + 미끼 |
| 짝 맞추기 | 창의 | 어울리는 둘 잇기(친구–먹이 등) | 짝 쌍 목록 |
| 무리 나누기 | 창의 | 기준대로 분류(하늘·땅·물 등) | 항목 + 분류 바구니 |
| 무늬 잇기(패턴) | 창의 | 반복 무늬 완성 | 패턴 토큰 + 빈칸 |
| 순서 따라가기 | 창의 | 순서대로 길/단계 따라가기 | 순서 항목 |
| 선물 꾸미기(창작) | 창의 | 색·모양·스티커로 자유 창작 | 팔레트(색·모양·스티커) — **정답 없음** |
→ 새 템플릿이 필요하면 개발팀과 협의(추가 개발). 우선 8종으로 풍부하게.

## 4. 학습목표 코드 (활동에 매핑)
- **정서(CASEL, 누리 사회관계)**: `sel_self_awareness`(내 마음 알기) · `sel_self_management`(감정 다루기·기다리기) · `sel_social_awareness`(공감=감정이입) · `sel_relationship`(나눔·소통)
- **창의(교수 6도구, 누리 예술경험)**: `creativity_observe`(자세히 관찰) · `creativity_imagine`(상상·유추) · `creativity_pattern`(패턴) · `creativity_transform`(모양 바꾸기·도형) · `creativity_design`(색·균형) · `creativity_compose`(통합·콜라주)
- 한 세션 = 정서막은 SEL, 창의막은 창의 6도구로 자연스럽게 분포. **감정이입은 두 트랙의 다리**.

## 5. 역할별 가이드라인

### 5.1 유아교육·아동발달 전문가 (커리큘럼/감수 리드) — 가장 핵심
- 모든 활동을 **연령(3–5 / 6–9) 발달에 맞게**: 3–5는 단순·구체·짧게, 6–9는 한 단계 심화.
- 활동↔학습목표(§4) 매핑 검수. 정서는 **"기술 연습"**(감정 인식·표현·공감)만 — 기분치료·정서조절 치료 ❌.
- 창작 활동은 **정답 없음=참여**. 평가는 점수가 아니라 **관찰 가능한 활동량**.
- 안전·발달 적합성 최종 게이트(아동 콘텐츠는 사람이 반드시 검수).

### 5.2 아동 콘텐츠 작가 (스토리텔러)
- 시즌 아크는 **열린 결말** — 아이의 선택·창작이 이야기를 완성("나만의 이야기책").
- 캐릭터 보이스(말투)·짧고 따뜻한 내레이션. **읽기 전 아이 기준**(귀로 듣는 글).
- 매 세션 = 한 친구의 작은 감정 사건 + 나만의 해결. 무섭거나 슬픔이 과하지 않게.

### 5.3 애니메이터·일러스트레이터
- 캐릭터 시트(표정 세트: 기쁨·슬픔·놀람·화남 등 — "표정 읽기" 활동에 필요).
- 활동별 자산 목록(§3 자산 형식)에 맞춰 제작. 아이패드 **가로** 화면 기준 해상도.
- 재미(juice) 동작 스펙: 정답 시 캐릭터 환호/점프, 별·confetti, 탭 바운스, 오답 부드러운 흔들림. (`prefers-reduced-motion` 대응)

### 5.4 성우 (또는 TTS 디렉션)
- 캐릭터별 톤(§2.2 `voice`). **또박또박, 약간 느리게**(미취학).
- 녹음 단위 = 활동별 `voiceLines`(안내·칭찬·격려·힌트) + 내레이션. 파일명=라인 id.
- 현재는 Gemini TTS 아동음성으로 stand-in 중 → 성우 녹음으로 교체.

## 6. 콘텐츠 규칙 (가드레일 — 반드시 준수)
- **포지셔닝 언어**: 부모 대면은 미래역량 구체어(사고력·문제해결·표현·자신감). "정서/창의 교육"·"영재"·"치료" 단어 금지.
- **점수·등수·또래비교·능력 단정 ❌** (아이·부모 모두에게). 관찰 가능한 활동/강점 서사만.
- **안전**: 만 3–9세. 폭력·공포·상업유도·다크패턴 ❌. 모든 콘텐츠 사람 검수 후 공개.
- **의학 클레임 ❌**(ADHD 치료·정서 치료 등). 개인정보=PIPA/COPPA 준수(아동 데이터 최소).
- **자동재생 금지** — 아이가 탭해서 진행(학습자 제어).

## 7. 납품 형식 + 품질 체크리스트
- **납품**: 세계 1개 = (세계관·시즌아크 1) + (캐릭터 4–6) + (세션 시나리오 N) + (활동 = 템플릿×내용) + (캐릭터/자산 아트) + (음성 라인). 작가·교육전문가는 **구조화 문서/스프레드시트**로, 개발팀이 `<world>.ts`로 옮김(또는 추후 authoring UI).
- **품질 체크**: ☐연령 적합 ☐학습목표 매핑 ☐정답없는 창작=참여 ☐포지셔닝 언어 ☐안전·검수 ☐가로 화면 ☐음성 라인 완비 ☐15–20분 분량(활동 5–6 + 도입/클로저).
