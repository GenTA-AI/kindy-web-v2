## 1. 아키텍처 — 모리의 이야기 도서관

**우산 세계 = 모리의 이야기 도서관.** 모리(크림+세이지 책 정령)는 도서관에서 가장 오래된
책에서 태어난 존재이자 호스트다. 마을에서 **유일하게 화면 밖 아이를 볼 수 있다**(4번째 벽
= 세션 가이드의 캐논 명분). 아이가 모리와 함께 **책을 펼치면** 그 세계로 들어간다.

- **책 = 세계.** 각 책은 자기 지리·작은 캐스트·분위기를 갖는다. 모리는 모든 책에 공통.
- **아이는 여행자.** 모리와 책을 옮겨 다니며 각 세계의 사건을 돕는다.

## 2. 큰 틀 스토리 — 관통 미스터리 "빈 마지막 페이지"

모리 책의 **마지막 페이지는 비어 있다** ("이 이야기의 끝은 아직 안 쓰였거든" — 바이블 떡밥).
각 세계에서 아이가 사건을 도와 만들어 내는 **"이야기 빛"**이 그 페이지를 한 줄씩 채워 간다.

- **제품 정합**: 이야기 빛 = 활동 완료 보상 = 앱의 마음 정원 씨앗과 **동일 캐논**(중복 개념
  만들지 않음). 모험 하나 완료 → 이야기 빛 한 줄기 → 마지막 페이지가 한 줄 채워짐.
- **초개인화 정합**: "내가 이 이야기를 완성한다" = 아이가 주인공인 느낌. 보이지 않는 AI.
- **호기심 엔진**: 페이지가 다 채워지면? = 장기 미스터리(시즌/세계가 늘수록 천천히 공개).

## 3. 공통 규칙 (꼬꼬마을 바이블 계승 — 위반 금지)

- **물리법칙**: ① 마음빛(감정을 알아채고 이름 부르면 가슴에 빛; 어두운 감정도 빛; 억누르면
  안개) ② 반짝 아이디어(생각을 여러 갈래로 = 별가루; 정답 없어 안 꺼짐).
- **빌런 없음.** 갈등의 원천은 **감정·관계·자연**(비·안개·기다림·바랜 색)뿐. 각 세계의 "문제"는
  악당이 아니라 **무언가가 조용히 바래거나 흩어진 것**이고, 아이가 되살린다.
- **안전 톤**: 위협적 어둠·이빨·재난·포식자 금지. 무섭지 않고 *조용한* 결. 해결은 항상 아이 손으로.
- **어휘**: 5세가 아는 낱말 + 새 감정 낱말 회당 최대 1개.

## 4. 4개 책(세계)

각 세계: 겉(아이 소구 테마) + 속(C6 도구 + 감정). C6 6도구가 4권에 고루 분산된다.

### 📕 책1 · 동물 마을 [기존, 갱신]
- **겉**: 언덕 위 둥근 마을, 마음나무, 이야기 도서관, 별빛 축제. 동물 친구들.
- **속**: 감정 읽기·공감(CASEL) + 관찰(observe)·통합(compose).
- **큰 틀**: 별빛 축제를 앞두고 친구들의 작은 마음 사건이 하나씩. 아이가 표정을 읽어 마음빛을
  켜고 반짝 아이디어로 도와 → 축제에 마음나무가 환해진다.
- **캐스트**: 모리(호스트) · **꾸미**(주인공·여림↔씩씩) · 방울(질문 던지는 친구) ·
  나옹(닮은점 찾는 친구) · 도토(숨은 다람쥐) · 올빼미 할아버지(밤의 지혜).

### 📘 책2 · 바다속 물빛 마을 [신규]
- **겉**: 물빛이 스며드는 산호 마을, 빛나는 해초, 숨은 생물. 포근한 바닷속(포식자 없음).
- **속**: 관찰(observe)·상상/유추(imagine) + 호기심.
- **큰 틀**: 마을을 밝히던 **빛나는 물길이 흐려졌다**(생물들이 작은 마음을 숨겨서, 안개처럼
  조용히). 아이가 자세히 관찰해 숨은 친구를 찾고 닮은꼴을 이어 물길을 다시 빛나게 한다.
- **캐스트**: 모리(책 타고 잠수) · **뽀글이**(호기심 아기 물고기·주인공) · 해미(느긋한 해마) ·
  조개 할머니(숨은 것을 아는 이).

### 📗 책3 · 별밤 하늘 세계 [신규]
- **겉**: 잠자리 전 밤하늘, 별자리, 구름 언덕, 달빛. 차분·경이. (bedtime 친화)
- **속**: 패턴(pattern)·상상(imagine) + 경이·차분.
- **큰 틀**: 밤하늘 **별자리 무늬가 흩어졌다.** 아이가 별을 이어 무늬(패턴)를 만들고, 별에 담긴
  이야기를 상상해 하늘 이야기를 다시 잇는다. 어둠은 무섭지 않고 포근한 밤.
- **캐스트**: 모리 · **별송이**(작은 별·주인공) · 구름이(폭신 구름) · 달 할머니(느린 말투의 밤 지킴이).

### 📙 책4 · 색의 정원 [신규]
- **겉**: 색이 피어나는 정원, 무지개 꽃, 색 웅덩이, 만드는 공방. 표현·만들기.
- **속**: 디자인(design)·변형(transform) + 표현.
- **큰 틀**: 정원의 **색이 바래간다**(색들이 자기 자리를 잊어서). 아이가 색과 균형으로 꾸미고
  모양을 바꿔 새로 만들어 정원에 색을 되살린다.
- **캐스트**: 모리 · **물감이**(팔레트 요정·주인공) · 꽃님이 · **무지**(무지개 등껍질 달팽이,
  바이블 캐논).

> **신규 주인공 이름(뽀글이·별송이·물감이)은 초안** — 변경 가능. 확정 전 대표/작가 검토.

## 5. 연결 장치

- **무지(달팽이)** = 앤솔로지 접착제. 무지개 등껍질로 책들 사이를 느리게 오가며("느린 건
  자세히 보는 거야") 아이를 다음 책으로 안내한다. 세계 간 카메오.
- **모리** = 모든 책의 공통 호스트 + 관통 미스터리(빈 페이지)의 주인.

## 6. C6 커버리지 (선별 라이브러리 정합)

| C6 도구 | 주 담당 세계 |
|---|---|
| observe(관찰) | 동물 마을 · 바다속 |
| imagine(상상) | 바다속 · 별밤 |
| pattern(패턴) | 별밤 |
| transform(변형) | 색의 정원 |
| design(디자인) | 색의 정원 |
| compose(통합) | 동물 마을 |

- 각 세계에서 만든 영상은 `library_videos.c6_focus`에 주 도구를 태깅 → `orderLibraryByWeakTool`이
  아이 약점에 맞춰 세계/영상을 선별. 4개 세계 = 6도구 커버 = 선별할 폭 확보.

## 7. 드리프트 해소

- **문제**: 바이블 정본은 꼬꼬 마을(꼬꼬·삐약이)인데, 코드(`animal-village.ts`)·영상
  (`mori-starlight-seed`, 꾸미의 반짝빛)은 동물 마을(꾸미·방울·나옹)로 갈렸다.
- **해소(승인)**: 동물 마을 캐스트를 **shipped된 꾸미·방울·나옹·도토·올빼미로 통일**(모리 호스트
  유지). `WORLD_BIBLE.md`의 꼬꼬/삐약이 표기를 이 캐스트로 갱신 → 영상 재작업 회피.
- **계승은 유지**: 물리법칙(마음빛·반짝아이디어)·지리(마음나무·이야기 도서관·안개 숲)·톤은
  바이블 그대로.

## 8. 범위 밖 (YAGNI / 후속)

- 세계별 상세 에피소드 대본, 캐릭터 프롬프트 시트, 영상 씬 분할 = 이 스펙 이후 authoring 단계.
- 시즌 아크 세부(각 세계 몇 화), 관통 미스터리의 최종 공개 = 후속.
- 4개를 넘는 추가 세계(공룡 골짜기 등) = 반응 검증 후 확장.
