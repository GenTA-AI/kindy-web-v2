## 2. 핵심 문제

교수 철학의 척추 = **"관찰 → 상상·유추 → 단순화 → 패턴 → 조합"의 단계적 추상화 곡선.** 그런데 시즌1은:

1. **①관찰이 0편.** 창의활동에서 "오감으로 자세히 보기"가 빠졌다. (정서축의 '표정 관찰'이 관찰을 대신하고 있지만, 그건 정서축의 사회적 인식이지 창의축의 적극적 관찰이 아니다.) 관찰은 나선의 입력단인데 입력이 비어 있다.
2. **②상상이 2편으로 몰림**(ep1·3). 시작점이 관찰이 아니라 상상이라, 곡선이 중간부터 시작된다.
3. **순서 무시.** 현재 배열은 imagine→pattern→imagine→transform→compose→pattern→design→compose. 추상화 곡선이 아니라 정서 아크를 따라 흩어져 있다.

`transform`·`design`은 각 1편으로 권장 최소치는 이미 충족.

## 3. 절충안 (권장)

**정서 아크를 깨지 않는다.** 정서축은 이야기 자체이고 5–10세 몰입의 뼈대다. 대신 **창의축에 두 가지만 보강**한다.

### 3-a. 시즌1 즉시 보강 (이야기 재촬영 없이 가능)
- **관찰 1편 주입**: ep1 또는 ep3의 창의활동 한 개를 `creativity_observe`로 교체/추가. 이야기를 안 건드리고 **활동 슬롯만** 교체하면 됨.
  - 후보: **ep1**("낯선 마을 도착") — 새 마을을 처음 보는 장면 자체가 관찰의 완벽한 명분. "마을에서 숨은 디테일 5개 찾기"(돋보기 탐험) 활동으로 ep1의 `divergentIdeas`(상상) 중 하나를 관찰 활동으로 바꾸면, ep1이 ①관찰 + ②상상을 둘 다 품는다.
  - 효과: 관찰 0→1, 상상 과다 완화. 6단계 전부 ≥1 충족.
- **나머지는 현행 유지**(transform·design 각 1편 이미 확보).

### 3-b. 시즌2 / 시즌1 리메이크 = 나선 순서 템플릿
새 시즌부터는 8세션을 **6단계 나선 순서**로 깐다(정서 아크와 동시 설계):

| 세션 | 창의 단계 | 정서(병행) |
|---|---|---|
| w1 | ①관찰 | self_awareness |
| w2 | ②상상·유추 | self_management |
| w3 | ③패턴 | social_awareness |
| w4 | ④변형·도형 | self_management |
| w5 | ⑤디자인원리 | relationship |
| w6 | ⑥통합·콜라주 | responsible |
| w7 | (2회차 나선) ①→③ 심화 | … |
| w8 | (2회차 나선) ④→⑥ 심화 | 통합 산출물 |

→ 한 시즌 안에서 나선을 1.3바퀴 돌아 관찰부터 통합까지 경험 + 후반 2편은 심화 반복.

## 4. 대안 (교수가 더 강하게 원할 경우)
- **풀 리오더**: 시즌1 8편의 창의 활동을 위 3-b 순서로 전면 재배치. 이야기 순서는 유지하되 각 편의 창의활동을 통째로 갈아끼움. 비용 큼(8편 창의활동 전부 재설계). post-20 콘텐츠 파이프라인 가동 시점에 적합.

## 5. 결정 요청
1. **3-a(관찰 1편 주입)** 즉시 반영할까? → 예이면 ep1 창의 슬롯 교체 초안을 바로 작성.
2. **3-b(나선 순서 템플릿)** 를 시즌2 정본 설계 규칙으로 채택할까?
3. 아니면 **4(풀 리오더)** 까지 갈까?

> 권장 = **3-a + 3-b**. 시즌1은 관찰 1편만 주입해 6단계를 완성하고(이야기 무손상), 나선 순서는 시즌2부터 정식 적용. 풀 리오더는 파이프라인 가동 후로 미룬다.
