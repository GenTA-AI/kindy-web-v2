# 교수 커리큘럼 → 어린이 "창의" 트랙 정밀 매핑

> 원본: 호서대 **이철재** 교수 「창의적 사고와 디자인」 14주 × 2차시 (슬라이드 28개 분석, `~/Documents/호서대/창사`)
> 교재: **「생각의 탄생」(Sparks of Genius, Root‑Bernstein)** — 13가지 생각도구
> 작성 2026-06-09. 목표: 이 대학 커리큘럼을 만 3–9세용으로 맞춤 변환, 아이별 스토리에 녹여 학습효과↑. 정서(CASEL)와 한 세션 통합 유지.

## 1. 원본 커리큘럼 구조 (2부 구성)
**전반부 (1–6주) = 창의적 "사고" — 생각의 탄생 13 도구**
- 1주 Intro: 창의성=나만의 생각, 나(정체성) 알기, 나를 표현(문장·단어·이미지·색), 마인드맵
- 2주: 생각을 다시 생각하기 — 느낌·직관→통찰, 실재와 환상의 결합
- 3주: **관찰** (수동적 보기 ❌ 적극적 관찰, 오감, 일상의 재발견)
- 4–6주: 나머지 생각도구 — **형상화·추상화·패턴인식/형성·유추·감정이입·몸으로 생각하기·차원적 사고·모형·놀이·변형·통합**

**후반부 (7–14주) = "디자인" 적용**
- 7–8주 **기하학** (도형, 기하학적 분석)
- 9주 **패턴 1** (패턴 인식)
- 10–11주 **디자인 PROCESS**: 생각→브레인스토밍→고정관념 탈피→융합→**유추(만다라트 3×3→9×9)**→추상화→패턴화/기호화/상징화→콜라주. (철학→목적→목표→키워드→컨셉)
- 12주 **디자인 원리**: 대칭(symmetry)·균형(balance)
- 13주 **패턴 형성**(분해·조립·창출) + **콜라주**(papier collé, 조각 모아 새로 만들기)
- 14주 **디자인 원리 — Composition**: 초점·시각위계·유도선·황금비·대비·여백·반복·그리드·삼분할 (11 rules)

**핵심**: 창의 = "관찰→상상→추상→패턴→유추→변형→통합"의 생각도구를, 도형·패턴·색·구성·콜라주로 손으로 실천. 정답 없음, 나만의 표현. **「생각의 탄생」13 도구 = 일반 Torrance facet보다 권위 있고 구체적인 프레임 — 이걸 채택.**

## 3. 재설계: 어린이 창의 scope‑and‑sequence (나선형, 연령 적응)
교수 진행을 어린이 발달에 맞춰 **나선형**으로 (만 3–5 단순 → 6–9 심화). 한 시즌 = 이 흐름을 한 바퀴:
1. **관찰** — 자세히 보기 (정서: 표정 관찰과 연결)
2. **상상·유추** — 머릿속 그리기, 닮은 것 찾기
3. **패턴** — 반복 찾고 나만의 무늬 만들기
4. **변형·도형** — 모양 바꾸고 조합 (기하학 어린이판)
5. **디자인 원리** — 색·대칭·균형으로 예쁘게
6. **통합/콜라주** — 조각 모아 "나만의 작품"으로 (시즌 클로저 = 나만의 이야기책에 수록)
※ **감정이입**은 매 세션 정서 파트와 동일 라운드에서 다뤄 두 트랙을 한 이야기로 묶음.

## 4. 구현 매핑 (코드)
- **curriculum-tags.ts (창의 목표 교체)**: 일반 Torrance 4개 → 교수‑근거 도구로. 예: `creativity_observe`(자세히 보기), `creativity_imagine_analogy`(상상·유추), `creativity_pattern`(패턴), `creativity_transform`(변형·도형), `creativity_compose`(디자인원리·콜라주/통합). anchor=누리 예술경험 + 「생각의 탄생」. interpretive 유지. tagForGameType: future_skills 창의 라운드를 이 도구들로 회전.
- **asset-pools.ts (creativity)**: 현행 색·모양·재료 유지 + **패턴 토큰** 보강(줄무늬·물방울·체크), 도형은 기하학(원·삼각·사각)으로 명시.
- **types/index.ts FUTURE_SKILLS_CURRICULUM**: 각 주차 창의 파트를 위 6단계 나선 순서로 매핑(주차 N=관찰, N+1=상상유추 …), 정서 사건과 결합.
- **engine.ts**: 창의 phase 라운드가 단계에 맞는 도구/자산/태그를 쓰도록(이미 phase 구조 있음 — 태그 셋만 교체).
- **부모 대시보드**: "창의" 지표 라벨을 교수 도구(관찰·상상·패턴·표현 등)로 — 단 부모 대면은 미래역량 구체어 유지(사고력·표현·문제해결).

## 5. 신뢰/포지셔닝
