# 아이별 가상 플레이테스트 리포트 & 설계 개정 v2.1

작성: CPO Office | 기준일: 2026-07-05 | 대상 문서: 제품기획서 v2.0 개정 · HERO 개발실행계획서 백로그 반영

> **정직성 선언 (필독)** — 본 리포트의 "1,000명"은 실제 아동이 아니라, **발달 연구 기반 파라미터로 생성한 가상 아동 코호트**를 제품 플로우 상태기계에 통과시킨 에이전트 시뮬레이션이다. 목적은 두 가지: ① 실아동 테스트 전에 예측 가능한 실패 모드를 설계에서 선제 제거 ② 실아동 검증(Phase B, 15–20명)의 **가설·계측·합격선을 수치로 생성**. 모든 수치는 예측치이며, 확정 권한은 Phase B 실측에 있다. 파라미터는 전부 '설계 가정 v1'로 명시되어 실측값으로 교체된다.

## 1. 방법론

| 파라미터 | 5세 | 6세 | 7세 | 가정 근거 유형 |
|---|---|---|---|---|
| 지속 몰입 예산(분, 중앙값) | 11 | 14 | 17 | 연령×주의지속 발달 휴리스틱, lognormal σ0.35 |
| 활동 전환 환기 배수 | ×1.45 공통 | | | 5단계 세션 구조의 다양성 효과 |
| 한글 단어 읽기 가능 | 25% | 60% | 90% | 국내 한글 해득 시기 분포 가정 |
| 첫 CP '수동 시청'(선택 가능함을 인지 못함) | 30% | 14% | 6% | 인터랙티브 미디어 초회 관찰 가정 |
| CP 반응 잠복(초, 중앙값) | 7.0 | 5.0 | 4.0 | 선택지 3택 시 ×1.35 |
| 드래그 과업 실패 | 25% | 12% | 6% | 유아 정밀 조작 발달 가정 |

**시뮬 플로우**: 키오스크(산만 환경) → A0 아바타·이름 → 첫 세션(CP 3회·게임 좌절 경로 포함) → 클로저 → D+1 행동. **비교군(arm)**: 세션 길이 20분 고정 vs 연령 적응(14/17/20) / CP 3택 vs 2택 / CP0 연습 선택 유무 / 이름 입력 초성 vs 음성 vs 추천 3택 / 키오스크 4스텝 vs 2스텝. 시드 고정(재현 가능), 스크립트 보존(playtest_sim.py → 데이터룸 09_Simulation).

## 3. 발견 8 → 설계 결정 → 티켓

**F1. 20분 고정 세션은 5세에서 붕괴한다 (완주 20%).** 몰입 생존곡선상 5세 절반이 14분 이전에 소진. → **결정 D1: 세션 길이 연령 밴드 기본값 14/17/20분** (P3 '무언 조정'의 초기값 확정) + 세션 내 환기 포인트를 5→6개로. 단 7세도 20분 완주 69%로 70% 게이트에 미달하므로 7세 상한도 18분 검토를 Phase B 가설로. → E13-16.

**F2. 첫 경험 게이트는 이미 안전하다 — 단, 정의를 바로잡는다.** '첫 세션 완료율 ≥70%' 게이트의 대상은 20분 정규 세션이 아니라 **10분 입장 여행**(C6 문서 §6)이며, 예측 통과율 5세 90%+. → 결정 D2: 게이트 문구를 "입장 여행 완주 ≥85% · 첫 정규 세션 완주 ≥65%(연령 적응 적용 시)"로 분리 명문화.

**F3. 5세의 40%는 첫 선택이 '선택'인 줄 모른다.** → **결정 D3: CP0 연습 선택 신설** — 1화 오프닝, 결과 무관한 선택("어느 문으로 갈까?")을 모리가 손짓·음성으로 유도, 성공 시 즉각 반응. CP0+2택으로 5세 무응답 40→23%. 잔여 23%는 실패가 아니라 시청 스타일이므로 **타임아웃 기본경로(모리가 대신 선택)는 페널티 0** 원칙 재확인, 무응답 3회 연속 시 다음 세션 CP 수를 2→1로 무언 감축. → E13-15.

**F4. 5세 CP는 2택이 정답.** 3택은 잠복 ×1.35로 타임아웃 급증. → 결정 D4: 연령 밴드별 CP 옵션 수 기본값 5세=2 / 6·7세=2–3(콘텐츠 계약에 옵션 가변 필수). 분기 구조(다이아몬드)는 불변 — 3택 노드는 5세에게 2택 서브셋 제공 + timeout_default 유지.

**F5. 초성 이름 입력은 5세에서 사실상 불가(18%).** → **결정 D5: 이름 짓기 3모드 우선순위 = 추천 3택(97%) → 음성(93%) → 초성(6·7세 한정 노출)**. 무입력 시 기본 이름("단짝아") 후 언제든 개명 가능 — 실패 경험 0 원칙. → E13-17.

**F6. 키오스크에서 이름을 빼면 5세 완료 43→70%.** 산만 환경 스텝 수가 지배 변수. → **결정 D6: 키오스크 데모 = 2스텝(단짝+색)만**, 호명 데모는 "친구야!"로 대체, 이름 짓기는 집(A0)에서. 부수 효과: **키오스크에서 아동 이름 수집 자체가 사라져 D-8 개인정보 리스크 원천 제거**. → E13-7 AC 개정.

**F7. 작업실 드래그는 탭으로.** 드래그 실패 25%→탭 배치 12%. → 결정 D7: A3 인터랙션을 '슬롯 탭 → 후보 탭' 2탭 방식으로 교체, 드래그는 6·7세 실측 후 옵션. → E8/A3 스펙 개정.

**F8. 5세 리텐션의 코어는 '새 것'이 아니라 '다시 보기'다 (D+1 회고 59%).** → 결정 D8: 책장 회고를 홈 CTA와 동급 접근성으로, "다르게 골라볼래?" 진입을 회고 종료의 유일 제안으로 유지. 콘텐츠 소진 모델(F5, 마스터플랜)의 재시청 계수 1.3을 5세 밴드 1.6으로 상향 — **5세 콘텐츠 소진 위험이 예측보다 낮다**는 좋은 소식. 재무·콘텐츠 계획 주석 갱신.

| 항목 | 5세 | 6세 | 7세 |

| 세션 길이 | 14분 | 17분 | 20분(18분 가설) |
| CP 옵션 수 | 2 | 2–3 | 3 |
| CP 타임아웃 | 15s + 모리 음성 리드 2회(6s·11s) | 15s + 리드 1회 | 15s |

| 작업실 | 탭 배치 | 탭 배치 | 탭(드래그 실험군) |

**화면 개정**: CP0(신설) — 오프닝 15초 내 등장, 두 문이 빛나고 모리가 번갈아 가리킴, 어느 선택도 동일 보상 반응 / A0 — 이름 스텝을 추천 3택 카드 우선 배치(음성 아이콘 보조, 초성 키패드는 6·7세 판정 시에만 노출) / K1' — 2스텝 + "친구야" 데모, QR 카피 유지 / A2 — 5세 밴드 음성 리드 스크립트 추가("손가락으로 콕 눌러봐!") / A3 — 2탭 배치, 슬롯 하이라이트 펄스. 전 개정은 기존 QA 12항목 + 신규 3항목(연령 기본값 적용 검증·CP0 존재·탭 배치)으로 머지.

## 5. 개발 파이프라인 개정

**신설 스테이지 — Usability Gate**: 각 릴리즈 Exit에 아동 지표 열 추가. R1 Exit 갱신: "입장 여행 완주 ≥85% / 첫 정규 세션(적응 길이) 완주 ≥65% / 첫 CP 무응답(5세) ≤25% / 이름 짓기 성공 ≥90% — 실측이 시뮬 예측 대비 −10%p 초과 이탈 시 원인 분석 후 게이트 재심".

**계측 추가 (이벤트 사전 v2)**: `cp_timeout`(리드 노출 횟수 포함) · `passive_first_cp` · `tap_miss`(좌표·타깃) · `assist_needed`(부모 개입 감지: 온보딩 중 성인 패턴 입력) · `replay_view` · `naming_mode_used` · `session_fatigue_exit`(분 단위 이탈 지점) — 전부 D-8 비식별 원칙 준수.

**신규 티켓**: E13-15 CP0 연습 선택(AC: 어느 선택도 동일 반응, 5세 리드 2회) / E13-16 연령 밴드 기본값 시스템(서버 설정, 무언 적용, 홀드아웃 가능) / E13-17 이름 3모드(추천 풀 100개 큐레이션·금칙 검사) / E13-18 키오스크 2스텝 전환(이름 수집 코드 제거 확인 테스트) / E15-1 아동 관찰 계측 7종 / E15-2 Phase B 키트(§6). 기존 E13-7·A3 관련 티켓 AC 개정.

## 6. Phase B 실아동 검증 프로토콜 (시뮬 → 현실 인수인계)

대상 15–20명(5/6/7세 균등, 성비 균형), 도서관 협조 공간, 보호자 동의(영상 미촬영 원칙·행동 코딩만) + IRB 수준 내부 윤리 체크. **과업 6**: ①키오스크 2스텝 ②A0(이름 3모드 무작위) ③입장 여행 10분 ④CP0→CP1 ⑤작업실 탭 배치 ⑥회고 재생 선택. 관찰 코딩 시트: 완료/보조요청/이탈시점/발화. **합격선 = 시뮬 예측 ±10%p** (예: 5세 첫 CP 무응답 예측 23% → 13–33% 밴드 내면 모델 신뢰, 초과 시 파라미터 교체 후 재시뮬). 산출물: 파라미터 실측표 v2 → 시뮬 재실행 → 게이트 수치 확정. 일정: R1 W6–7 (베타 50가구 이전).

## 7. 남은 정직한 간극

시뮬이 못 보는 것 — 정서 반응(재미의 질), 캐릭터 애착, 가정 내 방해 요인, 부모-아이 상호작용, 장기 신선도. 이는 Phase B 관찰과 베타 코호트만이 답한다. 본 리포트는 "무엇이 부러질지"를 예측했고, "얼마나 사랑받을지"는 예측하지 않았다.
