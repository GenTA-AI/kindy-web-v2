## 0. 제품 정의와 원칙

**"세상에 하나뿐인 우리 아이의 이야기가, 아이의 선택으로 매주 자랍니다."** — 아이(만 5–7세)는 자기 아바타로 주인공이 되어 매주 이야기를 살고, 선택은 world_state에 남아 세계가 아이를 기억한다. 부모는 그 선택들을 관찰 리포트로 본다.

**디자인 원칙 12 (전 화면 머지 기준)** — P1 미니멀: R1 한 화면 한 의도(아이 CTA 1) · R2 콘텐츠가 UI(아이 앱 탭바 없음) · R3 텍스트 다이어트(아이 ≤6단어, 음성이 주 채널) · R4 설정은 실패(부모 ≤7항목, 아이 앱 설정 0). P2 AI 비노출: R5 아이 표면 금칙어 0(린터 게이트) · R6 개인화의 세계관 번역(조정은 무언) · R7 부모 표면은 반대로 투명("어떻게 알았나요?" 필수) · R8 대기·실패의 세계관 연출. P3 최적화: R9 무드 시스템이 최적화의 표면(하늘·BGM·모리 톤만 변함) · R10 무언 조정 6종(§3 연령 기본값 포함) · R11 측정 없는 인터랙션 금지 · R12 탐험 보존(novelty 캡+낯선 씨앗 1).

**주인공 문법 5 (카피 린터 규칙)**: ① 아이는 2인칭 주인공("네가", "{이름}이가") ② 책 제목 = "{이름}와/과 {사건}" ③ 단짝은 아이가 지은 이름으로만 ④ 세계의 사건은 아이의 과거 선택이 원인("네가 도와준 보 고래가…") ⑤ 시스템·기능 언급 0.

## 1. 페르소나 · 여정 (정본)

서연(6세, 사용자) — "이야기 속 주인공이 되고 싶다" / 지현(36, 구매자) — "화면 시간을 아이를 이해하는 시간으로" / 사서 — "가족이 다시 오는 프로그램".

```
[도서관] 키오스크 2스텝(단짝+색) → 3분 체험(호명은 "친구야") → QR "집에서 계속" [결정 D6]
[부모폰] 랜딩(도서관 한정 혜택) → 온보딩 5단계(3동의·아동용 쉬운 고지·프로필=이름·출생연월 2필드)
[아이앱] 탄생 의식 A0(아바타+이름 3모드) → 입장 여행 10분(첫 관찰) → 첫 정규 세션(적응 길이)
         → 매 엔딩마다 내 책장에 책이 꽂힘 → D+1 회고 or 새 책 → 주간 루프
[부모]   세션3 후 첫 리포트(서사 근거) → 결제 → 주간 리포트+대화 힌트 → 월간 리캡(티어C)
```
이탈 회복 장치: 단계당 리마인드 1회 한도, QR 미가입 익명로그 30일 파기[결정 D-8], 미열람 리포트는 요약 푸시 문구만 교체.

## 2. IA (2공간 + 세션)

아이 앱: **내 책장(홈)** — 빛나는 새 책 1권(유일 CTA) + 이야기 문(장르 6문 = C6 축) 선반 + 꽂힌 책(회고) → 세션 플레이어. 부모 요소·외부 링크·설정 0 [결정 D-6 Web-first]. 부모 웹: 오늘 / 성장 지도 / 리포트 아카이브 / 설정·구독(해지 2탭·데이터 삭제 30일 SLA) + 온보딩.

## 4. 화면 스펙 정본 (14화면)

공통 AC = 원칙 12 + §10 QA. 카피는 실문구(변경 시 린터 통과).

**K1 키오스크 — 2스텝 데모 "네가 주인공"** [결정 D6]: ① "함께 갈 단짝은?" 4택 ② "좋아하는 색은?" 4칩 → 15초 데모(주인공 실루엣+단짝, 모리: "우와, 친구야! 네 이야기가 시작됐어") → K3 QR 카드("너의 이야기책, 집에서 계속 쓰자" + 도서관 가족 혜택). **이름 수집 없음**(개인정보 원천 제거). AC: 5세 완료 ≥65%[가정 70%→W3 실측], 무입력 60s 리셋, ks 사전로그 미연결.

**K2 3분 체험**: 영상 90s(선택 무드) + 성공 보장 미니게임 1 + 모리 칭찬. AC: 완주 ≥70%, 자막 기본.

**W1 랜딩**: 헤드라인 "모두에게 같은 영상이 아니라, 우리 아이에게만 맞춰 자라는 이야기." + 리포트 실물 1장 + 신뢰 칩 3(도서관과 함께·1탭 해지·결제 3일 전 알림) + CTA 1. ks 있을 때만 ₩19,000 배지 노출[결정 P-1].

**W2 온보딩 5단계**: 인증 → 보호자 확인+레이어드 3동의+아동용 쉬운 고지("모리는 네가 좋아한 놀이를 기억해. 엄마 아빠도 볼 수 있어")+키오스크 기록 연결 선택 → 프로필(이름·출생연월만) → 기기 페어링 6자리 → 완료. AC: 입력 필드 ≤5, 동의 없이 진행 불가, 완료율 ≥60%[가정→W3].

**A0 탄생 의식 — 아바타 + 이름** [결정 D5]: 3스텝(베이스 3·팔레트 8·단짝 6) 각 모리 음성 1질문 → 이름 짓기 **모드 우선순위: 추천 3택(성공 97%) → 음성(93%) → 초성(6·7세 판정 시만 노출)**, 무입력 기본 "단짝아"(개명 상시 가능, 실패 경험 0). 완료: 아바타 거울 등장 700ms + "만나서 반가워, {이름}!" AC: 총 <90s, 카메라·사진 요소 0(코드 부재 테스트), 뒤로가기 자유.

**A1 내 책장(홈)**: 하늘=오늘 무드, 모리 "새 이야기가 도착했어!", 빛나는 새 책 1권(유일 CTA), 선반=꽂힌 책들(표지=개인 스틸), [이야기 문→]. AC: 홈→재생 1탭, 카운터·배지 0, 텍스트 ≤6단어.

**CP0 연습 선택 (1화 오프닝 내)** [결정 D3]: 두 문이 번갈아 빛나고 모리가 가리킴 — "어느 문으로 갈까? 손가락으로 콕!" 어느 선택도 동일 보상(문이 열리며 반짝). 15s 무응답 → "그럼 모리가 열어볼게!" AC: 결과 서사 무관, 5세 리드 2회, 이후 CP 무응답 하락 계측(passive_first_cp).

**A2 세션 플레이어 + CP**: 풀블리드, 크롬 0. CP 진입=모리 대기 루프+카드(밴드별 2–3개, 아이콘+≤3단어, ≥120pt) — 5세 음성 리드 2회. 무응답 15s → "음, 오늘은 모리가 골라볼게!"(페널티 0). 선택 직후 **단짝 반응 컷 1.5s**(감탄만, "잘했어" 금지 — 분기 등가성) → 분기 재생 <300ms(프리로드). world_state 대사 예: "네가 도와줬던 보 고래야!"

**A3 별빛 작업실 — 탭 배치** [결정 D7]: 슬롯 탭(펄스 하이라이트) → 후보 탭 = 배치, 3슬롯, [완성!] 1버튼 → 씨앗 아닌 **오늘 책의 마지막 장면**에 반영 4s. 빈 슬롯도 완성 가능(정답 없음). 드래그는 7세 실험군 플래그.

**A4 클로저 — 책이 꽂힌다**: 이야기가 책으로 접힘 900ms → 책장 슬라이드 인 → "{이름}의 이야기가 한 권 늘었어. 내일 또 만나!" 자동 다음 없음. 표지=오늘의 개인 스틸(폴백 시 공유 표지 — 아이는 인지 불가).

**A5 회고 재생**: 꽂힌 책 탭 = path_taken 고정 재생, 종료 시 유일 제안 "다르게 골라볼래?" → CP 재진입. 이벤트 replay_view(C6 재시도와 구분).

**W3 첫 리포트(전환 화면)**: "오늘은 첫 관찰이에요" + 씨앗 6(2개 빛남) + **서사 근거 카드**("서연이는 목마른 친구들 중 아기 새에게 먼저 물을 줬어요" [어떻게 알았나요?⌄ → 3화 선택·일시 · "점수나 진단이 아니라 이번 주 관찰이에요"]) + 각주 "이야기 속 선택은 30년 창의교육 연구를 바탕으로 설계된 질문이에요" + 하단 도서관 혜택 ₩19,000·신뢰 블록·[{이름}의 이야기 계속 쓰기]. AC: 근거는 실 이벤트만, 열람→결제 전환 계측.

**W4 결제 / W5 설정·해지**: v1.0 스펙 유지 정본 — 가격 1개 크게(코호트별), 결제 버튼 위 "언제든 1탭 해지·결제 3일 전 알림", Toss 위젯; 해지 2탭·다크패턴 0·"돌아오면 {이름}의 책장은 그대로예요"·데이터 다운로드/삭제(30일 SLA).

## 5. 디자인 시스템 정본

컬러: cream #F4EAD2 배경 · sage #46763F 프라이머리·모리 · ink #231F18. 무드 4(gentle/lively/mystery/warm — 하늘·BGM·모리 톤 전용, UI 크롬 불변). 책등 컬러 = target_axis 6축 팔레트(부모 성장지도와 동일 체계, 아이는 색으로만 인지). 타이포: Pretendard — 아이 28/20 두 단계, 부모 24/17/15/13, 문단 ≤2문장. 레이아웃: 8pt 그리드, R20(아이)/R12(부모), 터치 아이 ≥120pt·부모 ≥44pt, 표지 3:4. 모션: 300–450ms ease-out, 보상만 700–900ms, 전환 메타포 '문·책' 2종, 플래시 ≤3회/초 금지·급대비 금지. 사운드: 대사 −16 LUFS, BGM 더킹 −12dB, 무드 BPM(gentle 60–76/warm 72–88/mystery 80–96/lively 96–112), 정답 효과음 없음(모리의 언어 반응만). 아바타·일러 룩 = 스튜디오 룩 프리셋 v1 동일 소스(캐릭터 바이블 SSOT). 접근성: 자막 기본, 전 인터랙션 TTS 병행, 부모 웹 WCAG AA.
