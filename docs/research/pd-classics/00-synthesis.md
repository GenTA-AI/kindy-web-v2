# PD 고전동화 전략 — 종합 판단서 (결정 안건)

2026-07-07 · 조사 4건 종합(정합성 01 / 파이프라인 02(mori-studio) / 저작권 03 / 경쟁 04) · 결정: 대표

## 한 줄 결론

컨설팅 방향("저작권 만료 고전을 원작으로, 인터랙티브 분기 유지")은 **피벗이 아니라 기존 계획에 이미 내재된 라인의 승격**이며, 4갈래 조사가 모두 같은 실행안으로 수렴한다: **"모리와 친구들이 연기하는 고전" 병행 라인(옵션 B)**.

## 수렴 근거 (조사별 핵심)

1. **정본 정합성(01)**: BRAND_DNA §3에 이미 "새 동화 각색 시 기존 6인 캐스트에 배역을 입힌다(연극 프레임)" 규칙이 명문화. R4 콘텐츠 목표에 "옛이야기 16" 기존재. 소재 에이전트도 정본상 PD 코퍼스 기반. 충돌 지점은 "원작 캐릭터 신규 생성"(옵션 C)뿐 — 캐스트·LoRA·브랜드 축적 원칙과 정면충돌.
2. **파이프라인(02)**: 분기 구조·플레이어·벤치·검수 전부 원작 독립 — 구조 변경 없음. 필요한 건 원전 추적 필드 추가(브리프: source_work/판본/PD 판정 메모, 대본: 원결말·대안결말 구분, 제거한 원전 요소 근거) + 검수 사전에 "고전 원전 잔혹성" 카테고리 보강.
3. **저작권(03)**: 6개 작품군 원작 골격 전원 PD 확정. **최대 함정 = 번역본·출판사 각색본·삽화의 별도 저작권**. 회피 실무: 여러 원전 대조→공통 원형만 추출→자체 재화(再話), 비주얼은 완전 자체(우리는 이미 KINDYTOY 룩·캐스트가 자체 창작이라 구조적으로 유리). 서비스명·에피소드명 KIPRIS 상표 검색 절차화. 판례 근거 확보(서울남부지법 2014나10460).
4. **경쟁(04)**: Cocomelon(PD 동요 → 30억 달러 인수)이 "고전+자체 캐릭터" 하이브리드의 최강 실증. 단 국내 최대 캐시카우는 오리지널 IP(뽀로로·타요) — 고전은 진입·검증 리스크 완화 전략이지 상한 대체가 아님 → 자체 캐스트 유지가 상한 보존. Netflix 키즈 인터랙티브 전량 철수(2024.12) 교훈: 신기함이 아니라 **반복시청 가치**가 관건 — 우리의 "선택→결말 분기+재시청" 설계와 일치하나 검증 필수.
