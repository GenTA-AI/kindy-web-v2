# 힉스필드(Higgsfield) 도입 검토 — 부결 (2026-07-09, 대표 결정)

> 배경: "페이블5 + 힉스필드 MCP 조합이 비싸더라도 최고 품질일 것 같다"는 가설을 실제 영상 생성으로 검증하려 함.
> 결과: **실제 생성 전에 카탈로그 대조만으로 결론이 났다.** 도입 부결, 기존 파이프라인 유지.

## 1. 무엇을 하려 했나

`out/pilot/video/S0/S0_sh1.png`(우리 키프레임)을 입력으로 힉스필드 I2V를 돌려, 같은 키프레임에서 나온 우리 seedance-2.0 클립(`S0_sh1.mp4`)과 프레임 대 프레임 비교할 계획이었다.

## 2. 실제로 일어난 일

- 힉스필드 MCP 연결·도구 로드 정상. 잔액 `credits: 10, plan: free`.
- fal 잔액 소진으로 fal 스토리지를 못 써서, 키프레임을 Supabase Storage 서명 URL로 올려 `media_import_url`로 임포트 성공(`media_id` 발급).
- `generate_video`(kling3_0_turbo, start_image=우리 키프레임) 호출 → **403 `job_minimum_basic_plan_required`**.
  → **무료 티어는 생성 자체가 불가.** 표시된 10크레딧은 사용 불가능한 숫자.
- 실제 생성을 하려면 3일 체험(카드 등록 필수, 3일 후 $49 자동결제, MCP 전용 100크레딧) 활성화가 필요.

## 3. 결론을 바꾼 발견 — 우리는 이미 이 A/B를 했다

힉스필드 영상 모델 카탈로그의 주력 2종이 **T3 실측 선발전(생성 AI 모델 선발전: 골든 태스크 20문항 × 모델별 생성 → Claude 심사위원 5축 채점)에서 이미 우리가 직접 돌려본 모델**이다.

| 힉스필드 주력 | 우리 T3 결과(2026-07-06) |
|---|---|
| `seedance_2_0` | **1위 85.3점** — 우리가 채택해 현재 쓰는 그 모델 |
| `kling3_0` | `kling-3.0-elements` **4위 77.8점**, 비용 5배, 프롬프트 준수 17.1/25로 최약 → **가성비 탈락 판정** |

즉 힉스필드는 우리가 이미 1위로 뽑은 모델과, 이미 탈락시킨 모델을 재판매하는 애그리게이터다. 정본 순위표: `docs/bench/T3-initial.md`.

## 4. 비용 — 같은 모델을 2.0~4.6배에 산다

seedance-2.0 6초 720p 클립 1개 기준:

| 경로 | 클립당 단가 | 우리 대비 |
|---|---|---|
| **우리(fal 직결)** | **$0.29** | 1.0× |
| 힉스필드 Ultra 연간($63/월·3,000cr) | $0.57 | 2.0× |
| 힉스필드 Ultra 월간($99/월·3,000cr) | $0.89 | 3.1× |
| 힉스필드 Plus 월간($49/월·1,000cr) | $1.32 | 4.6× |

(힉스필드 `seedance_2_0` 6초 720p std = 27크레딧, `get_cost` 실측)

**확장성 벽**: Plus 1,000크레딧/월 = 파일럿 한 경로 렌더 약 2회면 소진. Ultra 연간 3,000크레딧/월 = 월 2.5편. 에피소드 라이브러리를 쌓아야 하는 서비스 구조와 맞지 않는다.

## 5. 유일한 미검증 차별점 = Soul ID, 그러나 이미 더 싸게 이긴 문제

Soul ID는 캐릭터 일관성 기능이다. 우리는 같은 문제를 **LoRA v2**로 해결했고, T3 채점에서 **일관성 축 전 모델 1위(23.6/30)**를 기록했다. 학습 비용은 1회 $9.60(영구 자산). 힉스필드는 캐릭터 생성에 매월 크레딧을 계속 태우는 구조다.

## 6. 프리셋 품질 신호

우리 유아용 샷 프롬프트(모리가 손 흔들며 폴짝 뛰는 정적 컷)를 넣자, 힉스필드가 자동 추천한 프리셋은 **"IN THE DARK"**였다. 프리셋 라이브러리가 시네마틱·바이럴 숏폼용으로 튜닝돼 있고 미취학 아동물 도메인이 아니라는 신호. 우리가 사려던 "연출 프리셋 가치"가 우리 도메인에선 마이너스에 가깝다.

## 7. 결정

**부결.** 우리 파이프라인 유지:
- 영상: seedance-2.0 (fal 직결)
- 키프레임: 다중 캐릭터 → nano-banana / 단일 캐릭터 → flux-2-kindytoy-lora-v2
- 감독·연출: Fable 5

진짜 병목은 모델 품질이 아니라 **fal 잔액**이다. 힉스필드에 쓸 $49/월을 fal 생성비로 돌리면 같은 돈으로 2~4.6배 많은 클립을 뽑는다.

**재검토 트리거**: ① 힉스필드가 우리 T3 1위(seedance-2.0)보다 명확히 우위인 독점 모델을 확보 ② LoRA v2 일관성이 실제 에피소드 양산에서 무너져 Soul ID급 보정이 필요해질 때.
