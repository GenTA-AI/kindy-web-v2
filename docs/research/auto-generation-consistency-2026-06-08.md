# AI 자동생성 일관성·품질 — 근거 리서치 (요약)

> 생성: 2026-06-08 · deep-research (run wf_bcb5ab81) · 113 에이전트 · *결과 thin/대거 반증 → 결론 중심 요약*
> 질문: 사람 손 없이(human-out-of-the-loop) 새 시리즈·스토리·퍼즐·퀴즈를 일관·고품질·안전하게 자동생성 가능한가?

## 한 줄 결론
**완전 자동(사람 0)은 권장 안 됨. 부분 자동화 + 휴먼 게이트가 정답.** 적대적 검증에서 자동화 기법들의 강한 주장이 **대거 반증**(8건 refute) — "AI가 알아서 다 일관·안전하게 만든다"는 낙관은 근거가 약하다.

## 확인된 것 (high, 단 도메인 미스매치=가설)
- LLM 장편 서사는 일관성 버그를 만들지만 **자동 일관성 체커는 실현 가능**(F1 0.678, 재현율 ~55%) — 완벽 아님, 보조 신호용.
- 엔티티 일관성 RAG(E2RAG 등)은 아키텍처 우위만 약하게 — 만능 아님.

## 반증된 것 (낙관 경계 — 권고에 사용 금지)
- self-verify/self-refine 루프가 휴먼 QA를 대체한다 ❌(신뢰도 부족)
- 상징적 상태추적이 연속성 위반을 ~98% 자동 포착 ❌
- KG 목표노드 고정이 테마 드리프트를 크게 줄인다 ❌
- correctness-evaluator 에이전트가 단일정답/풀이가능성을 보장 ❌
- SAT solver in-the-loop가 퍼즐 풀이가능성을 "보장" ❌(부분만, 1-2)
→ 즉 자동 검증은 **보조**이지 사람 대체가 아님.

## 자동화 수준 권고 (3단)
1. **완전 자동 (사람 0, per-session)** — 게임/퀴즈 라운드 = **템플릿×파라미터(LLM 0, 결정적, 사전검증 자산풀)**. 퍼즐 풀이가능성은 결정적 생성이라 구조적으로 보장. ← 가장 안전한 자동화, 이미 우리 엔진이 이것.
2. **자동 생성 + 휴먼 게이트 (batch, 주간)** — 새 이야기/시즌(스토리 캐논 + 영상 대본)은 LLM 자동 생성하되 **published 전 사람 1회 검수**(안전·서사 일관성·품질). 4-6주 버퍼 미리 생성. 사람은 "요리법·견본" 승인이지 매 인스턴스 아님. AIG 자동 solvability/포맷 체크는 사전 필터로(사람 부담↓).
3. **사람 고정 (한 번 정의)** — scope-and-sequence(CASEL/Torrance 목표), 캐논 규칙, 자산 풀, 안전 정책.

→ 사람을 **O(child×week) → O(시즌/배치)** 로 줄이되 **5-10세 안전·서사 최종 게이트는 제거 불가**. (앞선 parent-dashboard·minimize-QA 라운드와 일관.)

## Caveat
근거 다수가 최신 arxiv·도메인(일반 NLP/시험/게임) → Kindy 정서·창의·아동 전이는 가설. 자동 일관성 체커·AIG 자동검증은 "보조 신호"로만 신뢰, 최종 판단은 사람.
