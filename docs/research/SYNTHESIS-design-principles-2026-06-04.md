## B. 어떻게 끌어들이나 (영상·인터랙션) — 근거 확실, 즉시 코드화

1. **응답 대기 8초 룰** — 영상/퀴즈가 아이 응답을 끝까지 기다리면 참여율 2배(0.35→0.73). 방송 표준 2초는 너무 짧음. → *플레이어에 8초 contingent pause 구현*
2. **Reprompt** — 미응답 시 질문 재반복이 재참여를 유발. → *퀴즈/인터랙션에 reprompt 단계*
3. **에피소드 반복 권장** — 같은 편 5일 반복 시청이 이해도·상호작용 모두↑. → *"다시보기"를 페널티가 아닌 권장 동선으로*
4. **3세+ 타깃 타당** — 영상 학습 발달 하한선 18-24개월.
5. **시리즈 구조** — 반복 캐릭터 + playful problem-solving(호기심·끈기·창의) 커리큘럼 프레이밍 (Sesame formative 근거).

## C. 게임 자동생성·난이도 (PCG/DDA) — 당신의 시그니처, 근거 확보됨

1. **PCG는 교육에 실제 적용 가능** ✅ — ML 기반 자동생성이 학습자 능력에 맞춘 콘텐츠를 휴리스틱보다 정확히 생성(Hooshyar, 한국 대학 저자, 영어읽기). 게임맵+산수문제 동시 자동생성 사례 존재(MathRun, 7-11세).
2. **AIG로 수천~수만 문항 대량생성** ✅ — 단일 item model로 33만 문항, 인지모델 후 수작업 대비 ~87배 빠름. → *꿈의정원식 "만개 스테이지"는 문항/레벨 자동생성으로 현실적*
3. ❌ **단, 자동생성 품질이 사람과 동등/우월하다는 주장은 반증됨** — 풀이가능성·난이도 보정·distractor 검증 **휴먼 QA 루프 필수** (search-based PCG: 필수 콘텐츠는 항상 풀이가능해야 함).
4. **DDA는 몰입의 최대 레버** ✅ — flow에 ES=.78(개인화 1.19). 적응형 튜터링 학습향상 g=.41(14,321명), ST Math 대규모 RCT 유의(⚠️medium, WWC "with reservations").
5. **아동 ZPD 수렴 입증** ✅ — 다차원 확률적 DDA가 148명 아동에서 1시간 내 각자의 근접발달영역으로 수렴.
6. ⚠️ **DDA를 단일 참여 엔진으로 과신 금지** — 성인 RCT(N=311)는 난이도-기술 균형이 재미·재플레이에 무영향. DDA의 작동경로가 flow가 아닐 수 있음. → *난이도뿐 아니라 자기효능감·진전감·자율성도 함께 설계*

## D. 게임 형식·20분 세션·부모 정서가치 (3차, 2026-06-05) — 근거 확보
> 상세: [game-formats-20min-session-2026-06-05](./game-formats-20min-session-2026-06-05.md). ★의학·치료(DTx/ADHD) 클레임 금지 + 근거상 '기분 개선·정서조절' 효능 클레임도 과장 금지.

**게임 형식 (퀴즈 탈피)**
1. **형식 선택이 학습을 좌우** ✅ — 게임기반학습 만3-8세 5영역 중간효과(인지 g=0.46…정서 g=0.35) 중 **퍼즐 g=0.63 vs 기타 g=0.31(≈2배)**(Alotaibi 2024, ⚠️Frontiers·medium). → 객관식 퀴즈 고착 금지, **퍼즐/문제해결형을 인지 코어**로.
2. **형식 다양화 자체가 레버** — 매칭/분류, drag-drop 구체물 조작(수학 CRA '구체'), 협동, 정서표현, 창작형을 회전.
3. **협동 > 경쟁(친사회)** ✅ — 협동 게임 15분이 나눔 행동↑(d=0.44, 만4-5세). 리더보드·경쟁 대신 **공동 목표**.
4. **게임 > 비게임 디지털(정서)** ✅소효과 — 디지털 '게임'만 부정정서↓(g=-0.19), 비게임 디지털은 비유의.
5. **터치 전제 OK**(d=0.46) — 단 수동시청 대비 우위일 뿐 실물·종이 대비 우월 아님(연령차등은 이 근거로 정당화 불가, 반증).

**20분 세션 청사진** (⚠️수치는 가설, A/B 검증 대상)
- 구조: `영상~3분 → 게임A(퍼즐) → 영상~3분 → 게임B(협동/정서표현) → (선택)정서 클로저` ≈20분
- 영상은 짧게 끊고 사이에 인터랙션(분절: retention d=0.32·transfer d=0.36; 학습자제어 시 d=0.98). 게임이 segment boundary.
- **학습자 제어로 다음 영상 진입**(고정 2초 자동전환 금지) + B의 8초 contingent pause·reprompt와 결합.

**부모(결제 고객) 정서가치 표현 — '기분' 아니라 '기술'**
6. **메시징: "공감·나눔·정서 인식 등 사회정서 기술을 연습"** ✅ — 출판편향 보정 후 견고한 건 SEL 기술(0.369)·친사회행동(0.353). **"기분 좋아져요"(affect 0.078 비유의)·"정서조절력 길러줘요"(비유의)는 사용 금지**. 'SEL'을 신뢰 앵커 용어로(270,034명 메타분석).
7. **eaSEL형 비동기 부모 채널** ✅설계선례(효능 modest) — AI가 영상서 SEL 순간 탐지 → 아동 성찰활동 + **부모가 영상 안 봐도 쓰는** 대화 스타터(CHI'25). 주간 리포트는 **'활동·기술 연습량'(관찰가능)** 시각화, 내면상태(기분/조절력) 단정 금지.
8. **다크패턴 회피 · 협동/진전감/자기효능감 기반 보상** — 강제 streak·손실회피 압박 지양(C와 일관).

## E. 시즌·cadence·적응형·부모통제 (4차, 2026-06-08) — 근거 확보
> 상세: [season-length-engagement-2026-06-08](./season-length-engagement-2026-06-08.md).

1. ⚠️ **시즌 길이 직접데이터 또 없음** → 디폴트 **4–6주(아크 1개=1시즌)** 가설(A/B). cadence 분리: 세션 주 2–3회 / 새 이야기 주 1편 / 시즌=주(챕터) 단위.
2. **반복을 두려워 말 것** ✅ — 만3–5세 단일 에피소드 5일 반복도 응시·참여·이해↑(Blue's Clues, N=108). 추가 세션 = 재시청 + 게임 변주.
3. ❌ **연속 서사(cliffhanger) 리텐션 우월 주장은 반증** → 각 에피소드 자기완결(robust) + 아크는 동기부여용 hybrid. 시즌 전환은 **항상 다음 세계 open loop**(완주 단두대 금지).
4. **적응형 = 전역 engagement 최대화** ✅(메커니즘 검증, ⚠️SEL/창의 전이는 가설) — 단일 난이도 다이얼 ❌. 연장=다면 engagement 상승, 종료=stopping-rule(추가 세션이 궤적 못 바꿈)+숙달/이탈. KPI=리텐션·자율감(학습성취 아님).
5. **부모 통제 = 자율지지형(권위적)** ✅ — "통제 vs 자율"이 아니라 **high structure + autonomy support**. 부모는 통제 레버를 원함(연령경계·cadence·세션상한). 좋은 디폴트+scaffolding, 강제종료·죄책감 ❌("내일 이어보기"). 행동통제 O / 심리통제 ❌. 효과는 A/B.

## F. 부모 대시보드·발달 가시성 + 포지셔닝 (5차, 2026-06-08) — 근거 확보
> 상세: [parent-dashboard-development-2026-06-08](./parent-dashboard-development-2026-06-08.md). **부모 대시보드(발달 가시성) = 진짜 리텐션 엔진** (월 결제일 가치 재확인).

1. ❌ **점수·등수·레벨 금지(만3-9세)** — 점수·보상은 내재동기 훼손, 아동에게 더 큼(d=-0.36); 또래비교는 아이 자기개념↓(부모는 도움된다 오인); 발달평가 합의(NAEYC/Katz)=관찰·포트폴리오. → **관찰 가능한 활동량**으로.
2. **법규(하드 게이트)** — FTC: in-game 향상 ≠ 실세계 능력(Lumosity $2M), "점수/레벨/능력향상" 단정은 검증된 측정을 함의 → 금지, 활동량 프레이밍. COPPA: 만13세 미만 VPC, 제3자/AI 공개 별도 opt-in (준수기한 2026-04-22).
3. **라벨: 미래역량 > 정서·창의 (데이터 확인)** ✅ — 부모는 'SEL/정서·창의' 추상 라벨 거부, 구체 스킬 만장일치(문제해결 1순위·목표설정 93%·자신감). → 카피·지표명은 **사고력·문제해결·문해·표현·자기주도·자신감** 구체어. (특정 단일 라벨 우위는 반증, 한국 A/B 필요)
4. **MVP 대시보드 7지표** (game_rounds 신호→미래역량 라벨, 점수 아님): 자기주도 시간·꾸준함 / 끈기·자신감(재시도) / 표현·문제해결(창작·퍼즐) / 소통·표현력 / 호기심·흥미폭(novelty) / 우리 아이 취향 프로파일 / 성장 하이라이트(마일스톤). 디벨롭: 주간 → 성장곡선·취향 → 시즌완주 **"나만의 이야기책"**.

## G. ⚠️ 여전히 빈틈 (누적 — 플랜 시 가설로 처리)

1. **세션/시즌 길이 직접데이터 — 4라운드 모두 미확보**. 분절 이점(→D)·반복 good·적응형 메커니즘(→E)은 확보했으나 최적 수치는 여전히 없음. **"2시간 미만"만 정당화**. → *시즌 4–6주·세션 주2–3회·20분·새이야기 주1편 모두 A/B 가설*. SEL/창의 효과 dosage(몇 주) 구체치도 공백.
2. ~~**한국 누리과정/2022 개정 교육과정 정렬**~~ ✅ **보완됨 (2026-06-05)** → [korea-curriculum-alignment-2026-06-05](./korea-curriculum-alignment-2026-06-05.md). 누리과정(교육부 고시 제2019-189호) 5영역·초등 2022 개정(고시 제2022-33호: 국어=별책5/수학=별책8/통합교과=별책15)에 우리 원칙 4개(3a CRA·일대일대응/3b STEM/3c 한국어 L1/3d 음악) 매핑 완료. **한국어 L1 실증 확보**: 음운인식 발달 단어→음절→음소(홍성인 2002, 음운인식↔초기읽기 r=.888 > 어휘 .448), 한국어→영어 음운인식 전이(Kim·Cho·Kim 2015), 한글 낱자→자소-음소 대응 순서(안성우·허민정 2011, N=1,043), body-coda 우세(Kim 2012). ⚠️매핑 일부는 해석적 bridge('일대일 대응'·'CRA'는 누리 원문에 없고 "물체를 세어 수량을 알아본다"가 anchor), L1→L2 전이 표본은 초5(만10-11세)라 만3-9세 외삽 미확립.
3. ~~**장기 리텐션 + 부모 리포트 설계**~~ ✅ **대체로 보완 (5차, →F)**: 대시보드=리텐션 엔진, 점수금지·법규·미래역량 라벨·다크패턴 안티패턴 확보. **잔여**: 리포트→리텐션 인과 효과크기(노출 vs 비노출)와 한국 부모 대상 지표명·시각화 A/B는 미확보(우리 instrumentation으로).
4. ❌ "귀여움=다크패턴" 주장은 반증됨 — 귀여운 디자인 자체는 조작이 아님.

## H. 전 근거 공통 한계
거의 모든 근거가 **서구(주로 미국) 표본**. 3라운드(2026-06-05)에서 **한국어 L1 음운인식·문해는 한국 아동 표본 실증을 확보**했으나(→ [korea-curriculum-alignment](./korea-curriculum-alignment-2026-06-05.md)), 조기수학·STEM·음악(3a/3b/3d)의 한국 복제연구는 여전히 미확인이라 한국 적용은 **가설**로 취급.
