# 11. 이야기 등대섬 (Story Lighthouse) — RPG 상세 기획 정본 (2026-07-14, 대표 선정)

> 컨셉 5안 중 대표 선정. 10(이야기 지도)의 **안전·측정 불변 조항과 2.5D 프리렌더 스택은 승계**하되, 세계관·루프는 본 문서가 신규 정본.
> 세 기둥(대표 지시): ① 간단한 메타버스(아바타 커스터마이즈) ② NPC가 말을 걸어 이야기가 시작(카톡 훅) ③ 이야기하며 나만의 거점을 가꿈.

## 1. 세계관

바다 한가운데 **등대섬**. 등대는 "이야기의 빛"으로 켜진다 — 아이가 이야기를 하나 마칠 때마다 불빛이 밝아지고, 수평선 안개 속에서 **새 섬**이 모습을 드러낸다. 세상의 이야기들(그림·음악·책·고전)은 **표류병**에 담겨 이 섬 해변으로 밀려온다. 등대지기는 모리(기존 IP 승계) — 아이의 첫 친구이자 안내자.

- **섬 = 콘텐츠 카테고리**: 그림 섬(명화 도슨트) · 노래 섬(클래식/오페라) · 책 섬(독서·고전명작) · 생각 섬(인문 질문) · 공방 섬(창의 만들기). 카테고리별 섬이라 "미술관에 인문학이 안 어울리는" 문제가 구조적으로 없음.
- **NPC = 이야기의 주인**: 각 이야기의 인물이 그 섬의 주민이 된다 — 쇠라의 낚시하는 여인(그림 섬), 피가로(노래 섬), 책 속 주인공들(책 섬). 수업을 마치면 그 NPC가 등대섬에 놀러 오기도 한다(거점 방문 연출).

## 2. 코어 루프 (1회 = 1이야기)

```
[카톡 플친] "🍾 {이름}의 해변에 표류병이 도착했어! 피가로가 편지를 보냈나 봐"
 → 링크 → 등대섬: 해변의 표류병 탭 → NPC 등장, 말을 건다 (이야기 도입)
 → 배를 타고 해당 섬으로 (아바타 이동 연출) → 수업(/lesson/*) = 이야기 본편
 → 완료: ① 등대 불빛 +1 (새 섬/새 길 공개 예고) ② 보상 = "이야기 조각"(건축 자재·가구·씨앗·부품)
 → 등대섬으로 귀항 → 거점 꾸미기 (조각 배치) → 부모 리포트에 오늘의 이야기·아이의 선택 기록
```

- 표류병은 **사라지지 않는다**(다크패턴 금지 — 아이의 속도 존중). 새 표류병 주기는 수업 배송 주기와 동일(주 2회) + 저비용 데일리 터치(복습 퀴즈 병, 오디오 명작 병).
- NPC 대사는 전부 **사전 생성+인간 검수** 콘텐츠. 실시간 자유 대화 없음 (불변 조항).

## 3. 기둥 ① — 아바타 메타버스

- **커스터마이즈 축**: 얼굴형·피부톤 / 머리 모양·색 / 눈 / 옷(상의·하의 또는 원피스) / 모자 / 소품(배낭·목도리·안경). 파츠는 KINDYTOY 2.5D 프리렌더(PoC 검증 완료: 4방향 시트 장당 $0.04) — 목표 **1만+ 조합**.
- 성별 고정 없음: 모든 파츠는 누구나 선택 가능. 시작 시 "마음에 드는 걸 골라봐" 3분 플로우.
- 아바타는 지도·수업 완료 화면·부모 리포트에 일관 등장 (아이의 정체성 앵커).

## 4. 기둥 ② — NPC와 다섯 역량

| 섬 | NPC 예시 | 역량 | 이야기 형식 |
|---|---|---|---|
| 그림 섬 | 낚시하는 여인, 화가 쇠라 | 예술·관찰 | 도슨트 수업 (기구현) |
| 노래 섬 | 피가로, 백조 | 클래식·표현 | 오페라/음악 수업 (제작 중) |
| 책 섬 | 고전 주인공(3형제 돼지 등) | 독서·이야기 구조 | 낭독+질문 수업 |
| 생각 섬 | 꼬마 철학자 부엉이 | 인문·질문 | "왜?" 대화 수업 |
| 공방 섬 | 발명가 두더지 | 창의·만들기 | "나라면?" 창작 과제 |

- NPC가 "말을 거는" 문안은 페이블이 아이의 지난 반응을 반영해 변주(§6) — 예: 지난주 원숭이를 오래 본 아이에게는 원숭이가 편지를 보냄.

## 5. 기둥 ③ — 거점 가꾸기 (동숲/꿈의 정원 코어)

- 온보딩에서 아이가 **거점 타입 선택**: 오두막 → (성장 트리) 성 / 궁전 / 비밀 정원 / 발명 공방 / 우주 기지. 선택제이므로 "여아=궁전, 남아=로봇" 같은 지정 없이 **그 아이만의 게임**이 됨. 중간 변경 가능(자재 승계).
- **이야기 조각 = 유일한 재화**: 수업 완료·창작 제출·복습에서만 획득(과금·시간제한 없음). 조각으로 방·가구·정원·장식 배치(격자 스냅, 드래그).
- 거점은 부모 리포트에 스냅샷으로 동봉 — "이번 주 서윤이의 섬" (결제 가치 가시화).
- NPC 방문 이벤트: 꾸민 거점에 수업 속 인물이 놀러 와 한 마디 남김(사전 생성 문안).

## 6. 페이블 개인화 (10 §4 승계)

- 밤 배치: (아이 반응 요약 + 월드 캐논) → ① 다음 표류병 후보 2~3 + 이유 ② NPC 인사 변주 ③ 거점 방문 문안 — safety-guardian(캐릭터명 마스킹 포함) + 인간 승인 큐 통과분만 배포.
- 전 아이 공통: 섬 지형·NPC 정본·수업 본편. 아이별 상이: 표류병 순서(=커리큘럼), NPC 문안, 거점.

## 7. 기술 (10 §5-1 승인 스택 승계)

- Phaser 3 + Tiled 타일맵 + 2.5D 프리렌더 스프라이트. `/island` 라우트(next/dynamic ssr:false). 수업 진입 = 트리거 존 → router.push(/lesson/*). 기존 /world 데모의 상태 로직 이식.
- 데이터: `child_island_state`(child_id, avatar_json, base_type, placed_items[], lighthouse_level, bottles[]). W1은 localStorage → W2 서버.
- 카톡: 플친 수동 발송(20가정) → 알림톡 템플릿(통판·채널 후) "표류병 도착" / "NPC가 말을 걸었어".

## 8. 단계 로드맵

- **I1 (2~3주)**: 등대섬 타일맵 + 아바타 커스터마이즈 v2(파츠 프리렌더 1차: 몸/머리/옷/모자) + 표류병→쇠라 수업→조각 보상→오두막 꾸미기(가구 6종) 데모
- **I2**: 노래 섬(이발사 수업 연결) + 거점 성장 트리 1단계 + 카톡 수동 발송 운영 시작
- **I3**: 서버 상태·기기 이월 + 페이블 표류병 개인화 배치 + NPC 방문 이벤트
- **I4**: 책 섬·생각 섬·공방 섬 + 알림톡 자동화

## 9. 불변 조항 (10 §5 전문 승계)

실시간 아동 AI 대화 금지 · 배포 전 인간 검수 · 측정 원칙(노출≠학습효과) · 다크패턴 금지(타이머·소멸·연속출석 압박 없음) · 랭킹/또래 비교 없음.
