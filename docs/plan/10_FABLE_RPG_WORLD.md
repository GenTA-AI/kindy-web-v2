# 10. 페이블 RPG 월드 — 아이별 탐험이 곧 커리큘럼 (기획 정본, 2026-07-13)

> 대표 지시: "모리의 숲 씨앗 모으기"를 대체. 모든 아이의 게임 **바탕은 같지만**, 새로운 스토리는 페이블이 만들어가고,
> 아바타가 세계를 탐험하며 **다음 이야기를 발견해야만 하는** RPG 루프로 지속 관심을 만든다.
> 상위 정본: 09(세션 루프)·로드맵(측정·안전). 충돌 시 안전 조항(§5)이 항상 우선.

## 1. 핵심 컨셉 — "이야기 지도(Story Atlas)"

아이마다 **자기만의 세계 지도**가 펼쳐진다. 지도 위 지역들(오페라 마을 세빌리아, 점묘 화가의 강가, 백조의 호수…)은
모든 아이가 공유하는 **공통 기반(월드 캐논)**이지만, 지도에 **다음에 열리는 길·만나는 사건·결말**은
아이의 반응 데이터(선택·정답·머문 시간·이모지)를 읽은 페이블이 아이별로 다르게 직조한다.

- 수업 1편 완료 = 지역 하나 탐험 완료 → 지도에 **새 길 2~3갈래**가 안개 속에서 드러남 (다음 주제 2지선다 큐레이션의 게임화)
- 아이(또는 부모)가 길을 고르면 → 그 길 끝의 다음 수업이 **그 아이의 커리큘럼**이 된다 — "이야기1→이야기2"가 자동 연쇄
- 아바타는 지도를 실제로 **걸어서** 이동 — 도착해야 수업이 열린다 (발견의 의식 = 리텐션 훅)
- 결말 분기: 수업 내 선택(다이아몬드 구조)이 지역의 상태를 바꾼다 — 세빌리아를 "대합창 축제"로 끝낸 아이와 "새 노래 작곡"으로 끝낸 아이는 서로 다른 마을 풍경·기념품을 갖는다

## 2. 왜 씨앗이 아니라 RPG인가

| 씨앗 모으기(현행) | 이야기 지도(신규) |
|---|---|
| 보상 = 수집(정적) | 보상 = **다음 이야기의 발견**(서사적) — 콘텐츠 자체가 보상 |
| 진행이 선형·동일 | 아이별 경로·결말 상이 → "내 세계"라는 소유감 |
| 부모 리포트와 분리 | 지도 = 커리큘럼 이력서 — 부모가 아이의 여정을 지도로 봄 |

## 3. 루프 (기존 자산 재활용 매핑)

```
[카톡] "서윤이의 지도에 새 길이 열렸어요" → /world (아바타·지도)
  → 아바타 이동(탭 이동, 조작 최소) → 지역 도착 → /lesson/{id} 수업 (09 루프 그대로)
  → 완료 → 지역 변화 연출 + 기념품(결말별) → 새 길 2~3갈래 공개
  → 아이가 길 선택(부모 리포트에 병기) → 페이블 야간 배치: 다음 지역 콘텐츠 준비
```

재활용: 아바타·지역 아트(`public/ip/generated/` 월드 자산), 다이아몬드 분기 엔진(story-director), 세션 이벤트 파이프라인(game_sessions/rounds), 큐레이션 2지선다(§2-3③) — **씨앗 UI만 지도 UI로 교체**, 데이터 계층 신설은 `child_world_state`(child_id, region_id, ending_id, opened_paths) 1테이블.

## 4. 페이블의 역할 — "월드 마스터"는 파이프라인에 산다

- **월드 캐논(공통 기반)**: 지역·캐릭터·규칙은 사람이 승인한 정본 (06 고전 극장 라인 계승)
- **아이별 직조**: 페이블은 (아이의 반응 요약 + 월드 캐논 + 학습목표)를 입력받아 ① 다음 길 2~3개 후보와 그 이유 ② 지역 도입 내레이션 변주 ③ 결말별 지역 변화 문안을 **사전 생성**
- 생성물은 반드시 **safety-guardian 검수 + 인간 승인 큐**를 거쳐 배포 (라이브 생성 없음)
- 전면 신작 에피소드는 주 2회 제작 사이클 유지 — 페이블 개인화는 "경로·연출·문안" 레이어에서 무한 변주 (제작비 불변)

## 5. 안전·측정 불변 조항 (이 기획이 절대 넘지 않는 선)

1. **아동과 실시간 자유형 AI 대화 금지** (로드맵 §7-1) — 페이블은 아이가 잠든 밤 파이프라인에서만 일한다
2. 모든 개인화 산출물은 배포 전 인간 검수 — 검수 없는 텍스트가 아이 화면에 닿지 않는다
3. 측정 원칙(09 §3) 유지 — 탐험·수집은 노출/참여 신호, 역량 갱신은 채점 가능 문항만
4. 다크패턴 금지 — 시간제한 보상·연속출석 압박 없음. "새 길"은 사라지지 않고 기다린다 (아이의 속도 존중)
5. 지도·아바타에 또래 비교·랭킹 없음

## 5-1. 렌더링 기술 방식 (2026-07-13 리서치 완료, 대표 결정 대기)

서브에이전트 2기 병렬 조사 결론:
- **3D(three.js+R3F)**: 가능하나 카톡 인앱(iOS WKWebView) 메모리 크래시가 최대 리스크(45MB GLB 실사례), 제품 v1까지 3~4개월+.
- **2D 도트(Phaser 3+Tiled)**: 데모 2~3주, 저사양·인앱 안전. 리스크는 도트 에셋 스타일 일관성(AI 4방향 뒤통수 뷰 취약).
- **권고 = 2.5D 프리렌더**(동키콩/초기 모동숲 방식): 소프트매트 3D 토이 캐릭터를 스프라이트로 프리렌더 → Phaser 2D 런타임.
  카톡 안전 + 티니핑 룩 유지 + 영상 파이프라인과 캐릭터 소스 단일화(학습 자산 재사용). 3D는 추후 상위 경험으로 얹되 2D가 항상 폴백.
- 채택 스택(확정 시): `/map` 라우트 = next/dynamic(ssr:false) Phaser 3 + Tiled JSON 타일맵 + 4방향 프리렌더 스프라이트,
  수업 진입 = 트리거 존 → 이벤트 → router.push(/lesson/[id]). 현 /world의 상태 모델(kindy:world)·잠금 로직 재사용.

## 6. 단계별 구현

- **W1 (MVP)**: /world 정적 지도(지역 3개: 세빌리아·그랑드 자트·다음 안개 지역) + 아바타 탭 이동 + 수업 연결 + 완료 시 길 공개. 페이블 개인화는 수동 큐레이션으로 시뮬레이션
- **W2**: child_world_state + 결말별 지역 변화 + 카톡 "새 길" 알림 문안
- **W3**: 페이블 야간 배치(반응 요약→경로 후보 생성→승인 큐) 가동
- **W4+**: 지역별 미니 탐험 요소(숨은 원숭이 찾기류 — 기존 hidden_friend 엔진 재활용)

## 7. 첫 콘텐츠 연결

세빌리아의 이발사(수업 2편, 제작 중)가 지도의 두 번째 지역 — 쇠라의 강가에서 "음악이 들려오는 길"을 따라가면 도착하는 구조로 온보딩 서사를 잇는다.
