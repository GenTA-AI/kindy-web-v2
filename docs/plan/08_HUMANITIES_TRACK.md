## 0. 한 줄

**"맞춤형"이라는 이름으로 두 연령을 동시에 잡는다.** 만 3~7세는 인터랙티브 고전·창작 동화로,
초등 저학년은 **인터랙션 없는 인문학 도슨트 영상**으로. 후자는 개인화 호명이 필요 없어 **지금 막힌 게이트를 우회한다.**

## 1. 아비투스 논지 — 왜 인문학인가

『아비투스』(도리스 메르틴)의 논지: 상류층을 가르는 것은 자산이 아니라 **문화자본**이다.
현대미술·고미술·회화·조각·오페라·발레·건축·성악·인문학적 소양은
중산층과 서민이 **경험할 기회 자체가 드문** 영역이고, 그 격차가 계급을 재생산한다.

**제품 명제**: 중산층 부모가 자녀에게 물려주고 싶지만 **경로를 모르는** 문화자본을,
매일 10분 영상으로 저렴하게 축적시킨다.

**AI 시대 차별화 서사**: 지식과 기술은 AI가 대체한다. 대체되지 않는 것은 **심미안과 해석력**이다.
"우리 아이가 그림 앞에서 무엇을 볼 수 있는가"는 AI가 대신 답해 주지 않는다.

### 1-1. 이 서사의 위험 — 고객 표면 언어 규칙

계급 상승 프레이밍은 한국 부모에게 강력하지만, 그대로 노출하면 **속물성·교육열 조장** 비판을 부른다.
`BRAND_DNA.md` §5·§6의 고객 표면 언어 규칙을 그대로 적용한다.

| 내부 언어(전략·투자 문서) | 고객 표면 언어(부모·마케팅) |
|---|---|
| 문화자본, 아비투스, 계급 재생산 | 교양, 심미안, 아이의 눈 |
| 상류층 진입 | 아이가 평생 지닐 취향 |
| 차별화 | 아이만의 시선 |

AI·진단·평가·점수 언어는 고객 표면에 노출하지 않는다(기존 규칙 유지).

### 2-2. 청구항이 우리 트랙 B 파이프라인과 일치한다

**청구항 1(독립항, 넓음)**
1. 이미지를 획득하는 단계
2. 이미지를 설명하는 **제1 텍스트**를 획득하는 단계 — 제1 텍스트는 **창작자의 견해 또는 큐레이터의 견해**에 대응
3. 제1 텍스트를 입력으로 하는 **제1 AI 모델**로 **제1 도슨트 영상**을 획득

**종속항**
- **제2항**: 제1 텍스트는 [작가 견해=제1 프리텍스트] + [큐레이터 견해=제2 프리텍스트]를 입력으로 한 **제1 언어 모델**로 생성
- **제3항**: 오디오 생성 프롬프트 → **제2 AI 모델** → 도슨트 오디오
- **제4항**: 영상·오디오·**자막 텍스트**를 시점에 배치하는 **사용자 입력** → 결합된 도슨트 서비스 영상
- **제6항**: **제3 AI 모델**로 제1 도슨트 영상보다 **고해상도**인 제2 도슨트 영상 생성
- **제7항**: **제1 도슨트 영상 = 720p, 제2 도슨트 영상 = 4K**
- **제8항**: 관람자의 견해를 추가로 이용

**청구항 9(독립항, 좁음)**: 위 전 과정을 하나로 묶고 마지막에 **관람자에게 제공**하는 단계까지 포함.

**명세서 【0065】**: *"상기 이미지와 기 설정된 상기 이미지에 대한 제1 텍스트를 이용하여 제1 도슨트 영상이 획득될 수 있다"*
→ **이미지 + 텍스트를 함께 입력하는 실시예가 명시**돼 있다. 우리의 I2V(원화를 시작 프레임으로 사용) 방식이 명세서에 포섭된다.

### 2-3. 이 특허가 트랙 B 설계에 부과하는 요구사항

특허를 **실시(practice)**하려면 파이프라인이 청구항 구성요소를 실제로 갖춰야 한다. 현 설계에 다음을 추가한다.

| 청구항 | 우리 구현 | 추가로 필요한 것 |
|---|---|---|
| 1·2항 (제1 텍스트) | Fable 도슨트 대본 = 제1 언어 모델 | 대본 스키마에 **`creator_view`(작가 견해)·`curator_view`(큐레이터 견해)** 프리텍스트 필드 신설. 대본은 이 둘을 입력으로 생성한다 |
| 1항 (제1 도슨트 영상) | 원화 → seedance-2.0 I2V | **우리 seedance 기본 출력이 이미 720p** — 제7항과 자연 정합 |
| 3·5항 (도슨트 오디오) | gemini-tts 내레이션 / minimax-music | **오디오 생성 프롬프트**를 제2 언어 모델(Fable)이 작가·큐레이터 견해로부터 생성하도록 단계 분리 |
| 6·7항 (업스케일) | **미구현** | **업스케일 단계 신설.** `fal-ai/topaz/upscale/video`. 제6항은 "고해상도"만 요구하므로 1080p($0.02/초)로도 충족. 제7항까지 실시하려면 4K($0.08/초) |
| 4항 (자막·배치) | 편집이 프로그램으로 배치 | **자막 트랙 신설** + 배치를 사람이 확정하는 **`사용자 입력` 단계**(앱 `/studio/queue` 승인 화면이 이 역할) |
| 8항 (관람자 견해) | 없음 | 선택. 부모·아이 반응을 대본 입력으로 넣으면 충족 |
| 9항 (통합) | — | 위를 모두 갖추고 **관람자에게 제공**하면 독립항 9 실시 |

**주의**: 특허는 **타인을 배제할 권리**이지, 우리가 자유롭게 실시할 권리(freedom to operate)를 보장하지 않는다.
원화의 저작권·미술관 사진 권리는 **특허와 무관하게 별도로** 해결해야 한다(§4).

#### P20250124 — 우리 파이프라인과 문언 그대로 일치한다

**청구항 1**: 줄거리·등장인물·장면번호를 포함하는 **콘티** 중 제1 장면의 **제1 텍스트** → **제1 AI 모델** → 이미지 프롬프트
→ **제2 AI 모델** → **복수의 이미지 프레임 후보들** → 제1 장면의 **제2 텍스트** → **제3 AI 모델** → 영상 프롬프트
→ 제2 프롬프트 + 후보 중 하나 → **제4 AI 모델** → 제1 영상.

**청구항 7이 결정적이다**:
> 제1 텍스트는 **등장인물의 외형, 배경, 사물을 포함하는 시각적 구성 요소**에 대한 묘사를 포함하고,
> 제2 텍스트는 **등장인물의 행동, 사물의 움직임을 포함하는 동적 요소**에 대한 묘사를 포함한다.

이것은 우리의 **`keyframe_prompt`(정적 구성) vs `motion_prompt`(제자리 움직임)** 분리와 문언상 동일하다.
2026-07-09 A/B로 우리가 실측 도달한 I2V 규율("그림이 아니라 변화를 묘사하라")이 **2025-08 청구항에 이미 적혀 있다.**

- **청구항 5·6**: 제1 프롬프트가 **초기 프레임용·최종 프레임용**으로 나뉘고, 초기·최종 프레임 후보를 함께 제4 모델에 입력
  → seedance의 `image_url` + `end_image_url` 경로와 대응
- **청구항 9**: 미리 설정된 기준으로 후보들에 **점수를 산출해 최고점을 선택** → 우리 VLM 심사위원(`claude-judge-live`)
- **청구항 8**: 후보들을 **UI에 표시하고 사용자가 선택** → `/studio/queue`
- **청구항 3**: 제1 영상 + 제2 영상 → **최종 영상** → 우리 `assembly`(이어붙이기)
- **청구항 4**: 수정 정보 + 영상 → **제5 AI 모델** → 수정 반영된 제3 영상 → QC 재생성 루프

#### P20250138 — 평가 스코어 기반 선택 UI

**청구항 1**: 사용자 입력 → **언어 모델** → **비디오 기획 정보**(클립 목록) → 클립 선택 → **복수의 이미지 프레임 생성**
→ 각 프레임의 **제1 평가 스코어** 획득 → 프레임 + 스코어를 **UI에 표시** → 선택 → **복수의 비디오 생성**
→ 각 비디오의 **제2 평가 스코어** → 비디오 + 스코어 UI 표시.

- **청구항 8**: 평가 스코어는 **이미지 평가 모델**로 산출 → 우리 VLM 심사위원
- **청구항 4·6**: 프레임 설명 입력 / 움직임 설명 입력 분리 → 다시 keyframe vs motion 분리

**설계 함의**: 우리 `/studio/queue` 승인 화면은 **후보 N장 + 평가 점수를 나란히 보여주고 사람이 고르는** 형태여야 한다.
지금 설계(단일 산출물 승인)로는 청구항 8·9와 P20250138을 실시하지 못한다.

**전략 함의**: 이 3건은 방어용이 아니라 **제품 설계도**다. 우리가 실측으로 도달한 결론들과 청구항이 일치한다는 것은,
오늘의 파이프라인이 곧 특허 실시 형태라는 뜻이다. 반대로, 특허를 실시하려면 **후보 다중 생성 + 스코어링 + 선택 UI**를
지금 설계에 넣어야 한다(현재 우리는 후보 1장만 생성한다).

## 3. 두 트랙 = 하나의 엔진, 두 연령

| | **트랙 A — 킨디 스토리** | **트랙 B — 킨디 아츠(가칭)** |

**차이는 화풍·인터랙션·길이뿐이다.** 코드 재사용률이 매우 높다.

### 3-1. 트랙 B가 MVP로 빠른 이유 (그리고 지금 막힌 게이트를 우회한다)

| 트랙 A의 병목 | 트랙 B |
|---|---|
| `{{child_name}}` 개인화 호명 → **gemini-tts 실패, Supertone 미확보로 출시 불가** | **호명 없음 → 이 게이트에 걸리지 않는다** |

수퍼톤도, 가창 모델도, 립싱크도, 분기도 필요 없다.

### 3-2. 트랙 B의 핵심 메커니즘 — 그림이 살아 움직인다

특허가 가리키는 그 형태다.

1. 퍼블릭 도메인 원화(고해상 오픈액세스) → 시작 프레임
2. **I2V**로 그림 속 인물·구름·물결·빛이 미세하게 움직인다(우리가 검증한 seedance-2.0 경로)
3. 도슨트 내레이션이 **무엇을 볼지** 알려 준다 — 구도, 시선, 색, 시대, 화가의 선택
4. 켄 번스 줌인으로 세부를 파고들고, 페이드로 넘어간다

07 방침이 그대로 적용된다: **키프레임(=원화)이 전부다.** 모션 프롬프트는 짧게, 카메라 무브 1개, 구도·색 보존.
이 트랙은 **원화가 곧 승인 프레임**이므로 캐릭터 일관성 문제 자체가 없다. 우리가 오늘 하루 싸운 문제가 여기선 존재하지 않는다.

## 3-3. 트랙 B 제작 규칙 (2026-07-09 파일럿 실측으로 확정)

### 원작 충실도 — 그림은 화가가 그리지 않은 것을 얻어선 안 된다

Fable이 처음 쓴 모션 프롬프트에 *"신사의 시가 연기가 피어오른다"*, *"점들이 별처럼 반짝인다"*,
*"빛이 테두리를 따라 흐른다"*가 있었다. **쇠라는 연기도 빛도 그리지 않았다.**
I2V가 그것을 만들어 내면 원작에 없는 것이 그림에 추가된다. 미술 교육 상품에서 이것은 결함이다.

→ `scripts/docent-script.ts`에 **원작 충실도 검증기** 신설. 위반 시 저장 실패 + 재집필(최대 3회).
- 금지: `smoke` `glow` `twinkle` `sparkle` `shimmer` `glint` `glimmer` `flicker` `star` `flame` `light rays` `vibrate` `pulse`
- 허용: 물결, 낚싯줄, 돛, 옷자락과 리본, 풀잎, 꼬리와 귀, 눈 깜빡임, 아주 느린 숨
- 카메라: `slow dolly in` 또는 `static` 중 하나만
- 첫 실행에서 `glimmer` 검출 → 재집필 후 통과

### 사실 근거 — 목록에 없으면 말하지 않는다

프리텍스트(`pretexts.json`)에 검증된 사실만 담고, 각 장면은 `fact_refs`로 근거를 단다.
존재하지 않는 사실 id를 인용하면 실패시킨다. "유일하게·최초로·딱 한 명" 같은 **사실을 넘어선 단정**도 금지.

**AIC 데이터에 기재된 "오른쪽 아래 서명"은 우리 3000px 원본에서 육안 확인이 되지 않아 대본에서 제외했다.**
확인하지 못한 것을 아이에게 "찾아보라"고 하지 않는다.

**조사에서 나온 중대한 정정**: 흔히 쇠라의 말로 인용되는 *"과학에 기반한 방법으로 현대적 종합을…"*은
**피사로가 1886-11-06 뒤랑뤼엘에게 쓴 편지**다. 그리고 "점묘법(Pointillism)"은 비평가들이 붙인 조롱조 명칭이며,
쇠라 자신의 용어는 **크로모뤼미나리즘(=디비저니즘)**이다.

### 형식 — 이야기꾼 + 그림 속 목소리 (대표 지시 2026-07-09)

내레이터가 존댓말로 이야기를 읊고, **그 화면에 실제로 보이는 등장인물이 장면마다 최대 한 명** 한마디를 거든다.
화면에 없는 인물은 말할 수 없다(코드가 강제). 동물은 짧은 소리만("킁킁", "끼익!").

### 립싱크를 쓰지 않는다 — 실측 판정

쇠라의 얼굴은 점으로 찍혀 입술 형태가 없다. VEED Fabric으로 흰옷 소녀 클로즈업에 립싱크를 시험한 결과
(비용 $0.15), VLM 심사위원 판정 **모션 2/20** — *"입 개폐가 명확히 드러나지 않아 사실상 정지 상태"*,
그리고 *"얼굴 세부에서 미세한 뭉개짐 가능성"*.

→ **트랙 B의 등장인물 대사는 화면 밖 목소리(보이스오버)다.** 원작 충실도 원칙과도 일치한다.
(트랙 A의 3D 토이 캐릭터에는 립싱크가 유효하다 — 07 §2 참조. 매체가 다르면 결론도 다르다.)

## 4. 콘텐츠 라인과 저작권 — 여기가 진짜 위험 구간

"저작권 없다"는 전제는 **절반만 맞다.** 06의 6단계 절차를 그대로 쓰되, 매체별 함정이 다르다.

| 매체 | 원작 PD 여부 | **함정** |
|---|---|---|
| **회화·고미술** | 화가 사후 70년 경과 시 PD | **미술관이 촬영한 사진에 별도 권리를 주장할 수 있다.** 평면 회화의 충실한 복제 사진은 창작성이 부정되는 경향이나 국내 확립 판례가 얕다. → **오픈액세스(CC0) 소스만 사용**: 메트로폴리탄, 시카고미술관, 레이크스뮤지엄, 국립중앙박물관 공공누리 등 |
| **조각** | 작가 사후 70년 | 3D 스캔·사진에 별도 권리. 현존 작품은 대부분 보호 중 |
| **건축** | 현존 건축물은 **저작물** | 한국 저작권법 §35② 개방 장소 항시 전시물의 복제 허용에는 **판매 목적 복제 제외** 단서가 있다. 상업 영상은 안전하지 않다. → **PD 고전 건축** 또는 자체 재현 |
| **오페라** | 대본·악보 PD(모차르트·베르디 등) | **특정 녹음물은 저작인접권**(실연자·음반제작자, 70년). 유명 음반을 쓸 수 없다. → 자체 연주 또는 합성 |
| **발레** | 이야기·음악 PD 가능(차이콥스키 1893년 사망) | **안무는 별도 저작물.** 현대 재안무·특정 공연 영상은 보호 대상. → 이야기와 음악만, 시각화는 자체 창작 |
| **성악** | 곡 PD | 녹음물 저작인접권 동일 |

**원칙(06 §3 계승)**: 원작의 **골격과 사실**만 취하고, **시각물과 음향은 자체 창작**한다.
프롬프트에 특정 미술관·사진작가·현대 작품명을 넣지 않는다.

**추가 원칙(트랙 B 전용)**: 원화를 화면에 쓰는 경우 **출처와 라이선스를 에피소드 아티팩트에 기록**한다
(`input_refs.license`). 이 기록 없는 원화는 렌더 차단.

## 3-4. 해상도와 업스케일 — 정지 회화에는 4K를 쓰지 않는다 (2026-07-10 실측)

### 업스케일 판정: 부결(트랙 B 한정)

`fal-ai/topaz/upscale/video`, 모델 `Gaia CG`(CG·애니메이션용), `recover_detail=1.0`, `noise=0`, `grain=0`으로
점묘 클로즈업 12초를 4K로 올려 심사($0.96). **충실도 23/30 — 우리 임계 24 미달.**

> *"Gaia CG 특유의 텍스처 재생성으로 점이 원본보다 선명하게 강조되거나 인공적으로 정돈된 인상이 있다.
> 프레임 간 점 위치가 미세하게 흔들려 텍스처 플리커 가능성이 있고 약간의 오버샤프닝 경향이 관찰된다."*

**근본 원인은 업스케일러가 아니다.** 원화의 최대 해상도는 **3000px**(AIC IIIF 제공 최대)이고 4K 프레임은 3840px다.
크롭 한 조각을 4K로 만드는 것은 **존재하지 않는 화소를 만들어내라는 주문**이며, §3-3의 원작 충실도 원칙을
마지막 단계에서 스스로 깨는 일이다.

- **트랙 B(정지 회화)**: 4K 업스케일 **하지 않는다.** 1080p로 납품한다.
- **트랙 A(3D 애니메이션)**: 원본이 720p 생성물이라 "진짜 해상도"가 없다. 청구항 6·7항의 업스케일은 **여기서 실시한다.**
- 청구항 6항은 "고해상도"만 요구하므로 1080p 출력으로도 충족된다. 4K(제7항)는 트랙 A 전용.

### 리샘플은 한 번만

초기 파이프라인은 **리샘플을 세 번** 겹쳤다: 원화 크롭 → 720p 키프레임 → 켄 번스 캔버스 확대 → 출력.
점묘 클로즈업은 원본 640px를 2배 확대했고, 누워있는 남자는 1440px를 1280px로 줄여 디테일을 버렸다.

→ **원화에서 곧바로 출력 해상도(1920×1080)로 한 번만 자른다**(`crop` → `scale=1920:1080:flags=lanczos`).
크롭 구도는 큐레이션 산물이므로 업스케일 배율을 낮추겠다고 크롭을 넓히지 않는다(구도가 무너진다).

### 편집기 결함 2건 (2026-07-10 수정)

1. **켄 번스 캔버스가 4:3이었다.** `scale=2160:1620`은 4:3이다. 16:9 키프레임을 넣으면 SAR이 4:3으로 박혀
   **DAR 64:27(=2.37:1)** 로 재생된다 — 화면이 21:9처럼 눌린다. 레퍼런스 프로젝트의 소스가 4:3이었음을 놓친 이식 오류.
   → 캔버스를 출력과 같은 종횡비로, `setsar=1`을 켄 번스와 정규화 두 곳에 명시. 회귀 테스트 2건.
2. **확대 시 화면 진동.** `zoompan`은 매 프레임 x·y를 정수로 내림한다. 캔버스가 작으면 1픽셀 계단이 보인다.
   → 캔버스를 출력의 **4배**로 키워 계단을 출력 기준 0.25px 이하로 낮춘다.

### 자막은 내레이션 전문이다

장면 요약 한 줄이 아니라 **모든 대사**를 자막으로 낸다(대표 지시 2026-07-10).
타이밍은 실제 TTS 파일 길이에서 계산한다(편집기의 딜레이 0.5초 + 대사 간 숨 0.35초 반영).
내레이터는 흰 글씨, **그림 속 인물은 옅은 노랑 기울임 + 화자명**으로 구분한다.
곡 설명 카드는 도입부 좌상단에 9초간(청구항 4항).

- 국내 1950~60년대 녹음은 구 1957년법 30년 규정으로 이미 만료 → PD.

## 5. 비주얼 방침 — 유아틱하지 않게

트랙 B는 KINDYTOY 화풍을 쓰지 않는다. 초등 저학년은 유아용 룩을 거부한다.
대표 지시: **《케이팝 데몬 헌터스》 같은 스타일라이즈드 애니메이션 느낌.**

**저작권 경계**: 화풍(스타일) 자체는 저작권 보호 대상이 아니다. 그러나
특정 작품의 **캐릭터·의상·로고·상징·특정 장면 구도**의 모사는 금지한다.
06 §3의 "브랜드/작가 화풍명을 프롬프트에 넣지 않는다" 규칙을 그대로 적용한다 —
내부 참조 용어로만 쓰고, 생성 프롬프트에는 **작품명을 쓰지 않는다.**

### 5-1. 힉스필드 재검토 — 논거가 절반만 뒤집힌다

2026-07-09 힉스필드 부결(`docs/research/higgsfield-verdict.md`)의 근거는 둘이었다.

1. **비용**: 우리가 이미 T3 1위로 뽑은 seedance-2.0을 2.0~4.6배에 재판매한다. → **이 논거는 그대로 유효하다.**
2. **도메인 불일치**: 프리셋 라이브러리가 시네마틱·바이럴용이라 유아물에 안 맞는다(유아 샷에 "IN THE DARK"를 추천했다).
   → **트랙 B는 바로 그 도메인이다.** 이 논거는 뒤집힌다.

따라서 판정은 유지하되 **재검토 트리거를 좁혀서 명시**한다:

> 트랙 B 파일럿 1편에서, 우리 파이프라인으로 얻을 수 없는 특정 시네마틱 샷(카메라 프리셋·조명 연출)이
> 실제로 발생하면, 그 **한 샷에 한해** 힉스필드 프리셋을 실측 비교한다. 프리셋이 없는 일반 샷은 여전히 fal 직결이다.

근거 없는 전면 도입은 여전히 부결이다. 같은 모델을 2~4.6배에 사는 것은 트랙이 바뀌어도 변하지 않는다.

## 6. 사업 서사

## 8. 착수 제안

트랙 B는 오늘 검증된 파이프라인만으로 즉시 파일럿이 가능하다. 순서:

특허 청구항을 실시하는 순서로 배열한다(§2-3).

1. 오픈액세스 원화 1점 선정(대표 큐레이션) + 라이선스 기록(`input_refs.license`)
2. **프리텍스트 2벌 확보**: 작가의 견해(창작 의도·시대 배경) + 큐레이터의 견해(해석·미학적 가치) — 청구항 2항
3. 도슨트 대본 1벌 (Fable = 제1 언어 모델, 선형·3분·초등 저학년 어휘) — 청구항 1·2항
4. 원화 → I2V 미세 모션(720p) + 켄 번스 줌인 — 청구항 1·7항
5. 오디오 생성 프롬프트(Fable = 제2 언어 모델) → 내레이션 VO — 청구항 3·5항
6. **업스케일 720p → 1080p/4K** (`fal-ai/topaz/upscale/video`) — 청구항 6·7항
7. 자막 트랙 + 배치 확정(사람) → 결합 — 청구항 4항
8. 편집: 페이드 + 이어붙이기 → 관람자 제공 — 청구항 9항
9. 대표 검수 → 트랙 B 정본화

**추정 비용(3분 = 180초 에피소드)**: I2V 생성 $2~4 + Fable 대본·오디오 프롬프트 $0.5 안팎
+ 업스케일 1080p $3.60 / 4K $14.40 (fal 실측 단가 $0.02·$0.08 per second).
