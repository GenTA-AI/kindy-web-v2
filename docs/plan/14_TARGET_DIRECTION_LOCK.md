# 방향 확정 — 런칭 타깃 = 초등 저학년 (2026-07-21)

대표 확정. track2-validation(발달·전략 검토) + AI 실현가능성 판단을 근거로 방향을 잠근다.
이건 새 방향이 아니라 기존 '7~10세 피벗'으로의 복귀 — 그동안 '유치원~초등저학년'으로 넓어졌던 표기를 되돌린다.

## 결정
- **런칭 타깃 = 초등 저학년(만 7~9세) 중심.** 취학 직전(6~7세) 자연 포함.
- **유아(만 3~5세)는 런칭 범위에서 제외.** PMF 확인 후 위로/아래로 확장 검토(narrow+premium).
- **핑크퐁·하츄핑식 중독성 경쟁은 하지 않는다.** 그 바(히트 노래·방송급 캐릭터 풀애니)는 유아(2~5세)용이자 AI 자동생성 불가 영역(가창 게이트·모션 드리프트). 초등 저학년은 흥미·이야기·실음원·참여로 몰입 — AI가 칠 수 있는 바.

## 왜 (한 줄씩)
- **AI 실현가능성**: 우리가 잘하는 것 = 삽화 키프레임·내레이션·도슨트 구조·실제 명작/명음원 큐레이션. 못하는 것 = 히트급 가창·방송급 풀모션. 초등 저학년 타깃은 못하는 영역(핑크퐁 중독성)을 요구하지 않는다.
- **발달 적합**: 7분 도슨트는 7~9세(구체적 조작기)용. 3~5세(전조작기)엔 주의지속·미학단계 모두 미스핏(track2-validation).
- **시장**: 아비투스/문화자본은 한국 부모에게 약함(예술취향→성적 전환 안 됨을 직관). 초등 저학년 '학교준비·읽기·표현·집중 + AI가 대체 못 하는 심미안'이 정기결제 정당화.

## 그대로 가는 것 (해자·논지)
- 아비투스/문화자본 = **내부 전략 논지**로 유지(대표 BM·특허의 뿌리). 고객 표면 언어만 재프레이밍.
- 특허(제10-2830011호)·큐레이션 권위(국제전시 3회)·'살아 움직이는 명화' 파이프라인 = 경쟁 키즈앱이 못 따라오는 해자.
- 세션 루프(09): 영상→질문→읽기→창작→회상.

## 바뀌는 것 (표면)
- **구매 동기 프레임**: 아비투스/문화자본(표면) → '학교 전 읽기·표현·집중력 + AI 시대 아이만의 눈'(09 카피 전면).
- **포맷**: 수동 감상 도슨트 → **세션 루프가 히어로**, 도슨트는 '수업 도입부'. 08 트랙B '인터랙션 없음'은 09가 오버라이드.
- **연령 정본**: 문서 간 상충(08 2트랙·09 통합·13 3~7중심) → **초등 저학년(7~9세)으로 정본 확정.**
