# 09. 제품 정본 v2 — 통합 인문 세션 루프 (2026-07-13)

> 트랙2가 문서상 "주간 영상 구독"에서 실제로는 **개인화 세션 루프**로 진화한 것을 정본화한다.
> 상위 근거: `트랙2_마케팅_가격_런칭플랜.md`(§0-1~0-3 교정 포함) · `docs/research/kindy-7-10-learning-video-roadmap-2026-07-12.md`(학습 설계 정본) · `docs/plan/08_HUMANITIES_TRACK.md`(제작 정본).
> 이 문서가 기존 문서와 충돌하면 이 문서가 우선한다 (제품 정의에 한해).

## 1. 제품 정의 (한 문장)

**"명화·클래식·고전 이야기를 매개로, 부모와의 대화로 시작해 아이의 반응을 따라 자라는 인문·정서·창의·독서 통합 세션 구독."**

- 파는 단위: 영상이 아니라 **세션(15~25분 수업 1회)** — 영상(의미 단위 분할) → 질문·퀴즈 → 실제 읽기 → 창작 → 회상.
- 포지셔닝 카피: "읽고, 느끼고, 생각하고, 만드는 힘." (07-13 랜딩 반영)
- 미술 단독 교육으로 보이게 하지 않는다 — 명화는 목적이 아니라 이야기의 시작(§0-1 계열 교정).

## 2. 사용자 루프 (퍼널 → 리텐션)

```
쇼츠/Threads → 랜딩(kindy.kr) → /first-story (무료 샘플, 로그인 無)
  → 카톡 채널 친구추가 → 온보딩(부모 대화·동의 3종) → 얼리버드 구독(포트원 빌링)
  → [주 2회 새 세션 + 저비용 데일리 터치] 카톡 발송 (요일 고정 없음, §0-3)
  → 아이 세션(웹): 영상 → 질문 → 창작 → 이모지 피드백
  → 세션 완료 → 부모 알림(알림톡, 통판·채널 개설 후) + 리포트 타임라인
  → 주간 리포트(관찰 문장) + 다음 주제 2지선다 → 큐레이션 반영 → 반복
```

## 3. 측정 원칙 (로드맵 P0에서 확립 — 불변 조항)

- 노출(시청·완료·자동선택)은 학습효과가 아니다 — `isAssessableRound` 게이트.
- 관찰되지 않은 신호에 중립값을 지어내지 않는다 — 관찰 가중 재정규화.
- 부모 리포트는 점수·등급·또래비교 금지, `한 일 / 관찰 근거 / 받은 도움 / 불확실성 / 다음 활동` 구조의 관찰 문장만.
- C6 표시에는 "검사·진단 아님" 고지 상시.
- 효능 주장은 통제 연구(로드맵 P4) 전까지 금지 — 사용성·안전·과정 증거만 공개.
