# 07. 영상 제작 방침 — 씬 타입·키프레임 우선·에이전트 분업

작성: 2026-07-09 | 상태: **실측 근거 확정, 대표 승인 대기**
근거: 당일 A/B 실측(`out/pilot/ab/`), 립싱크 스모크(`out/pilot/lipsync/`), 외부 조사 3건, 레퍼런스 프로젝트 `GenTA/bm/art&science/ocean-edu-imagen`.

## 0. 한 줄 결론

**영상 프롬프트는 레버가 아니다. 키프레임이 레버다.** 대사는 생성하지 말고 립싱크로 붙이고, 움직임은 짧게 끊어 빠른 컷으로 넘긴다.

## 1. 실측 — 영상 프롬프트 정교화는 무효

같은 키프레임·같은 시드에서 모션 프롬프트만 바꿔 3갈래를 생성하고, T3와 동일한 VLM 심사위원 5축으로 채점했다.

| 샷 | legacy(한국어 한 문장) | dense(조밀 80단어) | dense-v2(I2V 규율 50단어) |
|---|---:|---:|---:|
| S0_SH1 (모리+삼형제, 10초) | 89 | 89 | 89 |
| S1_SH3 (모리 단독, 7초) | **91** | 83 | 86 |

- 다중 캐릭터 샷은 **완전 동점**. 단독 샷은 **가장 단순한 legacy가 우세**.
- 조밀 프롬프트가 진 축은 두 번 다 **일관성(consistency)**. 심사평: *"셋째돼지의 안경이 프레임에 따라 흐릿해지거나 사라진다."*
- 원인: Seedance 6단 공식(주체+동작+환경+카메라+스타일)은 **T2V용**이다. I2V에서는 키프레임이 이미 외모·배경·조명·화풍을 확정했으므로, 그것을 다시 서술하면 모델이 앵커에서 벗어난다. 전 벤더 공통 규칙: **"그림이 아니라 변화를 묘사하라."**
- 부수 발견: legacy 클립에서도 심사위원이 dolly-in을 확인했다. **Seedance 내부 재작성기가 카메라 워크는 이미 넣고 있다.**

**따라서 `shot-director`의 영상 프롬프트 집필은 폐기하고, 감독 역량을 키프레임으로 옮긴다.**
모션 프롬프트는 짧게 유지한다(제자리 동작 한 문장 + 구도·색 보존 절).

## 2. 씬 타입 3종 (레퍼런스 프로젝트 검증 + 우리 스모크 실측)

| 타입 | 파이프라인 | 길이 | 실측 단가 | 쓰는 곳 |
|---|---|---|---:|---|
| `lipsync` | 키프레임 + 우리 TTS → **VEED Fabric 1.0** | **TTS 길이에 자동 일치** | $0.15 | 눈맞춤이 필요한 결정적 대사만 |
| `motion` | 키프레임 → seedance-2.0 I2V | **4~6초 고정** | $0.26/5초 | 노래·후렴·폴짝 등 동작. 대사는 보이스오버 |
| `still` | 키프레임 → 정지 영상 + 페이드 | **대사 있으면 오디오+1.0초, 없으면 3초** | ~$0 (ffmpeg) | 전환·배경·감탄 |

**립싱크는 소수여야 한다.** 대사가 있다고 립싱크하면 에피소드 전체가 말하는 얼굴의 연속이 된다
(실측: 기계 규칙으로 분해하니 18샷 → 36컷 중 32컷이 립싱크). 유아 애니메이션의 대사 대부분은
움직이는 장면 위 보이스오버다. 씬 타입은 **감독(Fable)의 판단**이고, 코드는 제약만 강제한다
(`lipsync ⇒ 화자 1명 ∧ close_up|medium`, 에피소드 립싱크 비율 ≤ 50%).

파일럿 실측(2026-07-09, Fable 감독): 18샷 → **motion 15 · lipsync 2 · still 1**, $4.90.
Fable이 고른 립싱크 2곳 = 아이 이름 호명(참여 유도) + 핵심 교훈 대사. 그룹 후렴은 전부 motion.

### 2-1. TTS가 콘티보다 먼저다 (2026-07-09 발견)

모션 컷은 4~6초로 묶여 있는데 보이스오버는 그보다 길 수 있다. 파일럿 실측에서 **18컷 중 8컷의 대사가 클립보다 길었다**
(최악: 삼형제 자기소개 12.1초 vs 6초 클립, 복습 릴레이 10.8초 vs 6초).

- 대사 길이를 모르면 컷을 몇 개로 쪼갤지 정할 수 없다. **파이프라인 순서: 대본 → TTS → 콘티 → 아트디렉터 → 생성 → QC → 편집.**
- 긴 보이스오버는 **모션 컷 여러 개로 쪼갠다**(각 4~6초). 컷마다 다른 키프레임이 필요하다($0.039/컷).
  이것이 곧 "짧고 빠른 컷 전환"이다.
- `still` 컷 길이는 오디오가 정한다: **오디오 + 딜레이 0.5초 + 여유 0.5초.** 3초 고정은 **대사 없는 전환 컷에만** 해당한다.
- 레퍼런스 프로젝트도 TTS를 먼저 뽑는다(`--tts-only` → 영상).

**추정하지 말고 실측하라.** 글자 수 추정(0.22초/자)과 실측이 크게 어긋난다.
삼형제 자기소개 컷: 추정 12.1초 vs **실측 20.9초**. 연기 지시가 템포를 좌우하기 때문이다.

### 2-2. TTS 계약 — 이름 슬롯과 연기 지시 (2026-07-09 실측 버그 2건)

1. **`{{child_name}}`을 통째로 합성에 넘기지 마라.** 모델이 플레이스홀더 자리에 **이름을 지어낸다**.
   실측: `"{{child_name}}! 우리도 같이 지어 볼까?"` → 발화 `"재한 씨, 우리도 같이 지어 볼까?"`(whisper 받아쓰기).
   → 대사를 `[이름 세그먼트][본문 세그먼트]`로 쪼개 각각 합성한다. 이름 세그먼트만 아이별로 런타임에 교체한다.
   → 호격 조사는 우리가 정한다: 받침 있으면 `-아`, 없으면 `-야`. 모델에 맡기면 무너진다(T06 59점·T08 49점).
   → **분리해도 이름 자체가 틀린다.** 세그먼트로 뽑은 `"서윤아"`(1.25초)를 대표가 청취한 결과 **"서이다"로 들린다**(2026-07-09 확정).
     제미나이 프리셋 TTS는 짧은 고립 이름 발화를 감당하지 못한다.
     **이름 합성은 gemini-tts에서 제외하고 Supertone sona-2(음성 클로닝)로 이관한다 — 확보 전까지 개인화 호명은 출시 불가.**

2. **연기 지시가 발화 길이를 두 배로 만든다.** 셋째돼지에 "천천히 또박또박"을 지시하니 쉼표마다 끊어 읽어
   형제(5.4초·4.7초)의 두 배인 **10.8초**가 나왔다. 성격은 지시하되 **템포는 명시적으로 고정**한다
   ("말 속도는 또래와 같게, 끊어 읽지 말고 한 호흡으로") → 6.85초로 교정.

3. 캐릭터별 프리셋 보이스는 고정 매핑한다(모리=Kore, 첫째=Puck, 둘째=Aoede, 셋째=Charon, 센바람=Fenrir).
   연기 지시는 **대사와 분리해** 전달한다(합치면 라벨이 낭독된다 — T04).

### 립싱크 스모크 실측(2026-07-09)

- TTS 4.49초 → 립싱크 영상 **4.48초**. 길이 자동 일치 확인.
- 파일 스트림: 립싱크 = video+audio(우리 TTS 그대로), I2V = video only.
- 심사평: *"입이 크게 열리고 닫히며 대사하는 모습이 자연스럽고, 키프레임 대비 얼굴·앞머리·비율·색조가 유지되며, 펠트/플러시 질감도 살아있다."*
- **대표 확인: 싱크 양호.**
- I2V의 입 움직임은 우리 오디오와 무관하게 지어낸 것이다. 나중에 TTS를 얹어도 맞지 않는다.
- 비용 주의: 레퍼런스 문서의 $0.05는 우리 실측과 다르다. **실측 $0.15/요청.**

### 왜 이 구조가 "AI 티"를 줄이는가

생성 모델이 움직임을 지어내지 않으면 붕괴할 것이 없다. 뽀로로류는 상시 격렬한 움직임이 없고, 폴짝 뛰는 동작은 **구두점**이다. 움직임을 최소 지점에만 배치하고 나머지를 립싱크·정지로 채우면 드리프트 표면적 자체가 사라진다.
전환에는 **반드시 페이드**를 쓴다. 하드컷은 유아용에 부적합하다(레퍼런스 프로젝트 명문 규칙).

## 3. 콘티가 강제하는 제약 — 한 컷 한 화자

VEED는 이미지 속 **한 얼굴**의 입을 잡는다. 따라서 한 컷에서 여러 캐릭터가 차례로 말할 수 없다.
현 파일럿 `S0_SH2`(세 돼지가 한 컷에서 한 줄씩)는 **화자별 클로즈업 3컷으로 분해**해야 한다.
이 제약이 곧 "짧고 빠른 컷 전환"을 낳는다 — 품질 목표와 기술 제약이 같은 방향을 가리킨다.

**콘티 규칙**: 감독이 `lipsync`로 지정한 샷만 화자 1인당 1컷으로 쪼갠다. `motion`·`still` 샷은 쪼개지 않고 대사를 보이스오버로 얹는다.
같은 화자의 연속 발화는 한 컷으로 병합한다. 그룹 후렴(`char="전체"`)은 언제나 `motion`이며 립싱크하지 않는다.

## 4. 키프레임 일관성 규약 (질감 결함 해법)

A/B에서 심사위원이 세 번 반복 지적: *"참조는 펠트·플러시 질감인데 결과는 매끈한 플라스틱."*
립싱크 스모크의 키프레임에서는 이 결함이 사라졌다. 차이는 둘뿐이다.

1. LoRA 대신 **nano-banana + 승인 캐스트 참조 첨부**
2. 프롬프트에 명시적 일치 지시:
   `"MUST match the attached reference image EXACTLY: same face, same proportions, same colors, same soft felt-plush surface texture."`

추가로 레퍼런스 프로젝트의 비법: **캐릭터 시트만 넣으면 매번 달라진다. 직전에 승인된 씬 이미지를 함께 참조로 붙여야 일관성이 붙는다.**
→ 아트디렉터는 참조 목록에 (캐스트 시트 + 직전 승인 키프레임)을 함께 넣는다.

## 5. 에이전트 분업 — 판단은 Fable, 검증은 코드, 승인은 사람

| 단계 | 소유 | 현재 |
|---|---|---|
| 고전 선정·저작권 방어 | Fable `motif-scout` | 구현됨 |
| 대본·분기 설계 | Fable `story-smith` | 구현됨 |
| 아동 안전 검수 | 코드 `safety-guardian` | 구현됨 |
| 총괄·재집필 루프 | Fable `story-director` | 구현됨 |

| **콘티: 씬 타입, 화자 1컷 분해, 컷 리듬** | Fable `storyboard` | **구현됨(2026-07-09)** |

| 생성·재시도·로깅 | 코드 `gen-operator` | 스텁 |
| **보이스 캐스팅·스타일·믹스** | Fable + 코드 `voice-sound` | 스텁 |
| **드리프트 QC → 재생성 판정** | VLM 심사위원 `qc` | 심사위원만 있음, 루프 없음 |
| 편집·페이드·이어붙이기 | 코드 `assembly` | 스텁 |

**Fable이 하지 않을 것**: 영상 프롬프트 집필(§1로 무효), 기계적 규칙 검증(린터 소유), 픽셀 생성.
근거: Anthropic 공식 Fable 프롬프팅 가이드 — *"과도하게 규범적인 프롬프트는 출력 품질을 저하시킨다."* Fable은 Opus의 2배 단가·최저 속도다. 판단이 필요한 곳에만 쓴다.

**사람이 여는 문 3곳**: ① 고전 선정·저작권 판정 ② 캐릭터 디자인 승인 ③ 대본 승인.
그 이후 콘티·키프레임·생성·QC·편집은 무인으로 굴린다.

| 구성 | 현행(전 샷 I2V) | 신 방침(실측) |

| 키프레임 18컷 | $0.70 | $0.70 |

+6~8컷(동작 $0.26 + 키프레임 $0.039)이 추가돼 **$6.5 안팎**으로 수렴할 것으로 본다. 그래도 $9.02보다 낮다.
Fable 판단 비용(대본·콘티·키프레임·QC)은 편당 $2 안팎으로 추정한다.

## 7. 착수 순서

1. ~~`storyboard`~~ — 완료(2026-07-09). 후속: TTS-우선 순서 + 긴 보이스오버 컷 분할 + still 길이 오디오 연동
2. `art-director` — 키프레임 집필 + 참조 선택(§4 규약)
3. `assembly` — ffmpeg 정규화·페이드·concat
4. `qc` — VLM 심사위원 되먹임 루프(일관성 임계 미달 샷만 재생성)
5. `voice-sound` — 보이스 캐스팅·스타일·믹스(-16 LUFS). **Supertone sona-2 확보가 게이팅**(tts 채점 결과 참조)
6. 캐릭터 디자이너 — 신규 고전의 캐릭터 자동 설계·승인 프레임 생성

## 8. 미해결

- VEED가 한 프레임에 얼굴이 여럿일 때의 거동 미검증(§3의 1컷 1화자 규칙으로 회피 중).
- 노래·후렴 트랙: `minimax-music` 미실행. 음악 골든셋이 폐기된 물방울·무가창 BGM 기준 — **가사 있는 유아 노래로 재작성 필요**.
- `mmaudio-v2` 효과음 미실행.
- 클립 이어붙이기 미구현.
