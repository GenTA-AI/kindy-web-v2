## 1. 세계관 정본 (LOCK)
- **무대**: 햇살 가득한 **동물 마을**, 곧 **별빛 축제**. 아이는 마을의 새 친구로 초대받아 친구들 마음을 알아주고(정서) 나만의 방법으로 도와(창의) 축제를 완성. 시즌 끝 = **"나만의 동물 마을 이야기책"**. (`animal-village-season1.md` 유지)
- **모리 = 책정령 호스트/길잡이**: 키오스크 → 영상 → 가정 전 구간을 잇는 주인공·안내자. 4기분 변형(gentle·lively·mystery·warm)이 GACS 톤과 직접 연결.

### 역할 정리 (중요 — 마스코트 충돌 제거 / 컨펌 요망)
3개 세계가 흩어져 있어 정리한다. **웹 정본은 모리 + 동물마을로 단일화.**
- **모리** = 세계를 잇는 호스트·길잡이·내레이터 (기존 토토의 마스코트 역할을 흡수)
- **동물 친구들**(꾸미·방울·나옹·도토) = 정서 사건의 주인공 (그대로)
- **토토(토끼)** = 마을 안 단짝 친구 (호스트 역할은 모리로) — **확정 2026-06-19**
- **올빼미 할아버지** = 마을 이야기꾼(시즌 도입/마무리 내레이션, 모리와 공존 가능)
- **iOS 꼬꼬 마을**: 별도 앱 트랙. 웹 런치 우선이므로 웹=동물마을로 가고, 추후 IP 통일 검토(플래그).

## 2. 커리큘럼 (재확인 — 변경 없음)
정서=CASEL 5역량 / 창의=교수 6도구(관찰·상상유추·패턴·변형·디자인·통합) / 활동 8템플릿 / 2막 세션 / 시즌=나만의 이야기책. (상세 `authoring-guide.md`)

### 무료 체험용 데모 3세션 선정 (동물마을 내)
| 세션 | 친구·사건 | 주 도구(반응=진단축) | question_hold |
|---|---|---|---|
| 1. 꾸미 곰의 날 | 슬픔·위로 | 관찰 + 공감 | 꾸미 표정에서 마음 고르기 |
| 2. 방울이의 신나는 날 | 기쁨·자기조절 | 패턴 | 다음에 올 무늬 고르기 |
| 3. 도토의 숨바꼭질 | 두려움·용기 | 유추 + 관찰 | 숨은 친구/닮은 것 찾기 |
→ 이 3세션이 **관찰·패턴·유추·공감 4축** 반응 데이터를 만든다 = 1차 창의/정서 진단의 입력.

## 3. 핵심 메시지 → 카피 (LOCK된 메인 + 보조)
- **메인**: "우리 아이만을 위해, 매주 새로워지는 모험" / "아이의 반응에 맞춰 다음 이야기가 진화해요"
- **보조 신뢰줄(이제 허용)**: "30년 창의교육이 설계 · 『생각의 탄생』 사고도구 기반" — *이름 없이* "30년 교수", 책은 "기반/영감"까지만 (법무 §1 준수: 공식/감수 암시 금지)
- **CTA**: "무료로 시작 — 모험 3편 + 우리 아이 창의 진단"
- **부모 대면 금지어**: 점수·등수·또래비교 / "정서·창의 교육" 단어 / "공식·감수·인증" 암시. → 미래역량(사고력·표현력·자기주도) 언어로.

## 4. 인스타 광고 1차 — 크리에이티브 브리프 (카피·구성만, 비주얼=디자이너)

### 포맷 A — 아이 몰입 비포/애프터 영상 (9:16, 12~15s, UGC 느낌·실제 베타가정 촬영 권장)
- 훅(0~1s 자막): **"우리 애가 스스로 '더 하고 싶어'라고 한 건 처음이에요"**
- 비포(1~4s): 아이 심심·산만한 일상 컷
- 애프터(4~11s): 모리 영상에 푹 빠진 아이, 끝나자 "또 보고 싶어!"
- 마무리 자막+CTA(11~15s): "매주 우리 아이에게 맞춰 진화하는 모험" → "무료 체험 + 창의 진단"

### 포맷 B — 비포/애프터 진단 카드 (캐러셀 3장 또는 단일)
- 카드1: "체험 전 — 우리 아이가 뭘 좋아하는지, 뭘 잘하는지 몰랐어요"
- 카드2: "체험 후 — 서연이의 창의 프로파일: 패턴·상상 ★ / 곧 자랄 점 = 유추" *(점수 아닌 별·새싹 정성 표현)*
- 카드3: "매주 서연이에게 맞춰 진화하는 모험" → CTA "무료로 시작"
- 가드레일: 점수·또래비교 금지, 성장 서사만.

> 두 포맷 모두 **메인 메시지(매주 진화하는 초개인화 모험)**로 수렴, 미끼=무료 체험+진단. 비주얼 톤/레이아웃은 디자이너가 IP R3·브랜드 컬러로.
