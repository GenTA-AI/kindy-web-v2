## 3. 무료 체험 → 진단 → 전환 (핵심 엔진)
가입(카카오) → 관심사 → 무료 3세션 → 행동신호 수집 → **엄마 진단 리포트**(강점+곧 자랄 점, 점수 없음) → "이 부분이 자라요" → 결제링크.
- 데모 3세션(동물마을): ①꾸미 곰의 날(관찰+공감) ②방울이 신나는 날(패턴) ③도토 숨바꼭질(유추+관찰) → 관찰·패턴·유추·공감 4축 진단.
- "자동 진화" = 실시간 생성 아님. 즉시는 콘텐츠 풀에서 GACS 선택, 진화는 야간 배치로 그 아이 전용 생성 → 휴먼 승인 → 다음 세션.
