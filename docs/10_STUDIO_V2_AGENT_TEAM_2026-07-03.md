> 목표(대표 지시): "팝마트급 토이 캐릭터가 핑크퐁처럼 리듬감 있게 움직이고, BGM·효과음까지 전부 작동하는 진짜 애니메이션"을 만드는 에이전트 팀. 역할별 모델 선정·지침 포함.
> 근거: 딥리서치 107 에이전트(주장별 3표 적대 검증, fal 엔드포인트 라이브 확인 2026-07-03) + 오케스트레이터 직접 검증(MMAudio/MiniMax Music/Seed Audio 엔드포인트) + 자체 실증(VEED $0.72 클립, FLUX 계열 키프레임, 캐스팅 TTS 22개).

## 0. 핵심 결론 3줄

1. **전부 fal 하나로 됩니다.** 최신 모션 모델(Kling 3.0 "O3"·Seedance 2.0·Veo 3.1), 캐릭터 LoRA 학습(FLUX.2 이미지 $6.4/1000스텝·LTX-2/Wan 2.2 비디오), 말하는 캐릭터(OmniHuman $0.14/s), SFX(MMAudio $0.001/s), BGM(MiniMax Music $0.035/곡)까지 — 벤더 추가 없이 현 Next.js+fal 인프라로 v2 전체가 가능.
2. **"팝마트 룩" = 캐릭터 LoRA, "핑크퐁 모션" = 오디오 퍼스트 비트 그리드.** 프롬프트만으로는 토이 룩 일관성이 안 나옴 — 토이 룩 시안(대표 승인)으로 FLUX.2 LoRA를 학습해 룩을 고정하고, BGM을 먼저 생성해 BPM 비트 그리드에 컷 길이를 스냅시키는 것이 리듬감의 구현체.
3. **한국어 아동 음성은 ElevenLabs가 정책상 봉쇄**(아동 음성·아동 모사 성인 음성 모두 금지, 3표 검증) — 한국 벤더 **수퍼톤 Sona 2**(감정 연기 50+ 스타일, KO/EN/JA, Creator $14.99/mo)가 1순위, 단 아동 음성 제공 여부는 문서에 없어 **대표 직접 확인 게이트**. 폴백은 현행 Gemini 캐스팅 체계(이미 작동).

## 2. 핵심 아키텍처 결정

- **오디오 퍼스트**: BGM(BPM 확정) → 비트 그리드 → 대본 씬 길이 배분 → 모션 start/end 프레임이 비트 경계 포즈 — "음악에 맞춰 움직이는" 핑크퐁 문법의 공학적 구현. (검증된 공개 노하우 부재 → 설계로 해결하는 영역, 실증 필수)
- **룩 고정은 LoRA, 모션 일관성은 reference/element**: 이미지 단계 FLUX.2 LoRA(룩) + 모션 단계 Kling @Element/Seedance 레퍼런스(동작 중 일관성) 2중 앵커. v1의 승인 프레임 축적 루프는 LoRA 재학습 데이터셋으로 승격.
- **폴백 사다리 유지**: 신규 모델은 전부 실증 게이트 뒤에서 승격(OmniHuman→VEED, Sona 2→Gemini, Seedance 1.5→limited). v1 파이프라인은 언제나 동작하는 바닥.
- **Seedance 2.0 네이티브 오디오는 채택 보류**: 통합 오디오가 매력적이나 음악 품질 조악("not a music generator") + $0.30/s — 전용 스택(BGM/SFX 분리)이 품질·비용 우위.
- **Veo 3.1($0.40/s)은 마케팅 히어로 전용** 유지.

## 3. 단계 도입 (각 단계가 독립 데모 가능)

- **Phase 0 (진행 중)**: 현행 v1로 에피소드 1편 완주·검수 — v2 비교 기준선.
- **Phase 1 — 오디오 스택 (저위험·고체감)**: 음악감독+음향+믹싱 에이전트 추가 → 기존 limited 영상에 BGM·SFX·더킹만 얹어도 "진짜 애니메이션 느낌" 점프. +$0.2/편.
- **Phase 2 — 토이 룩 LoRA**: 대표와 토이 룩 시안 확정(HITL) → 캐스트 LoRA 학습 → 키프레임 교체. 실증: 같은 씬 v1 vs LoRA 비교 시트.
- **Phase 3 — 모션·비트 그리드**: Seedance 1.5 start/end frame 본편 + 오디오 퍼스트 재배선 + OmniHuman 실증.
- **Phase 4 — 히어로 통합**: Kling 3.0 element 히어로 컷 + Sona 2 전환(게이트 통과 시).

## 4. 사람 게이트 (대표)

1. **토이 룩 방향 승인** — 팝마트풍 3D 비닐 토이 시안 vs 현 2D 그림책(파스텔) 룩: 브랜드 정체성 결정. IP 복제 없이 룩앤필만.
2. **수퍼톤 가입 + 아동 음성 확인** — Play 보이스 라이브러리에서 아동 음색 존재·약관 확인(미제공 시 Gemini 유지).
3. **OmniHuman 실증 클립 승인** — 토이 캐릭터 1컷 생성($0.7 내외) 후 VEED와 비교 청취·시청.
4. 비용 승인선 상향 여부 — 표준 편당 ~$5-6 (현 limited $1.3 대비).
