# 카카오페이 정기결제 연동 플랜 (결정 보류)

## 현황

- Kindy 멤버십 월 구독은 **TossPayments v2 빌링**으로 구현됨 (`/subscribe`, 카드 정기결제).
- **TossPayments 빌링은 카카오페이 정기결제를 지원하지 않음** (검증됨 — 토스 빌링은 카드 결제수단 한정). 일반결제(단건)에서는 카카오페이가 가능하지만, 월 구독 자동 청구에는 쓸 수 없음.
- 현재 `/subscribe` UI 의 카카오페이 버튼은 **"준비 중" disabled** 상태.

## 옵션

### A. 카카오페이 SID 직접 연동

- 카카오페이 온라인 결제 API 의 정기결제: 최초 결제 시 `SID`(정기결제 고유번호) 발급 → 이후 `/v1/payment/subscription` 으로 서버 청구.
- 장점: 수수료 단일 계약, 카카오 UX 그대로.
- 단점: PG 가 둘이 됨 (토스 + 카카오) — 결제 기록·환불·정산·webhook 처리 이원화. 카카오페이 가맹 심사(CP 등록) 별도 필요.

### B. PortOne(구 아임포트) 통합

- PortOne V2 빌링키 발급으로 토스·카카오페이·네이버페이를 단일 API 로 통합.
- 장점: 결제수단 추가가 설정 수준, webhook/정산 단일화.
- 단점: 중계 수수료 추가, 기존 토스 직연동 코드 마이그레이션 비용.

## 결정 보류 사유

1. 구독 초기 단계 — 카드 정기결제만으로 수요 검증 가능.
2. 카카오페이 가맹 심사에 사업자/통신판매업 정보 확정 필요 (현재 env placeholder).
3. 결제수단별 전환율 데이터가 쌓인 뒤 A/B 중 선택하는 것이 비용 대비 합리적.

## 재검토 트리거

- 구독 결제 이탈 단계 분석에서 "카드 등록" 단계 이탈이 유의미하게 높을 때.
- 월 구독자 100명 돌파 시점 (PG 수수료 협상력 발생).
