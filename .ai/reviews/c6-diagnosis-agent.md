3. **멱등성** — PASS. `claimRound` runs `update({growth_processed_at: now}).eq('id', roundId).is('growth_processed_at', null).select('id')` and returns `Boolean(data?.length)`. Under Postgres READ COMMITTED, a concurrent second update re-evaluates the `is null` predicate against the row after the first commits, matching zero rows → empty returned set → `skip`. supabase-js `.select()` after update returns the affected rows, so the length check is accurate. `loadRecentRounds` excludes the current row via `.neq('id', roundId)`.
