## 2. 핵심 기술 결정

### 2-1. TTS: Gemini 2.5 Flash Preview TTS
- 모델: `gemini-2.5-flash-preview-tts`
- 캐릭터별 프리빌트 보이스 고정 (Puck, Leda, Aoede 등)
- **비법**: 스타일 지시문을 대사 앞에 텍스트로 삽입
  ```
  "7살 여자아이가 말하는 것처럼 아주 높고 맑은 목소리로..."

  안녕! 나는 물결이야.
  ```
- "절대 어른 목소리가 아닌" 같은 부정 지시가 효과적

### 2-2. 캐릭터 보이스 매핑

| 캐릭터 | Gemini Voice | 설정 |
|--------|-------------|------|
| 물결이 | Puck | 7살 여자아이, 밝고 활기참 |
| 조개 | Leda | 8살 남자아이, 걱정하는 여린 톤 |
| 물고기 | Aoede | 9살 여자아이, 또박또박 관찰자 |
| 산호 | Fenrir | 8살 남자아이, 힘없고 슬픈 톤 |
| 내레이션 | Kore | 10살 여자아이, 어린이 뉴스 앵커 |
| 돌고래 | Charon | 9살 남자아이, 답답하고 힘든 톤 |
| 바다거북 | Despina | 8살 여자아이, 불안하고 떨리는 톤 |
| 고래 | Enceladus | 10살 남자아이, 차분하고 깊은 톤 |
| 주인공 | Puck | 8살 여자아이, 놀라는 톤 |

### 2-3. 물결이 감정별 스타일
물결이는 메인 캐릭터로 씬마다 감정이 달라서 스타일 오버라이드 적용:
- **bright**: 기본 밝은 톤
- **serious**: 진지하게 궁금해하며, 천천히 또박또박
- **excited**: 신나서 빠르게, 보물 발견한 느낌
- **storytelling**: 동화책 읽어주듯, 신비롭고 몰입하는 톤
- **whisper**: 속삭이듯, 경이로운 순간

## 3. 씬 타입별 처리 방식

### 3-1. 대사씬 (lipsync)
캐릭터가 직접 말하는 씬. 립싱크가 필요.

```
키이미지 + TTS.wav → VEED Fabric 1.0 → 립싱크 영상
```

- VEED는 이미지 속 캐릭터의 입을 자동 감지하여 오디오에 맞춰 움직임
- 해상도: 720p (VEED 기본)
- 영상 길이는 TTS 오디오 길이에 자동 맞춰짐

### 3-2. 내레이션씬 (narration)
캐릭터가 없거나 풍경 위에 내레이션이 깔리는 씬.

```
키이미지 → 정지 영상 → TTS 오디오 합성 (ffmpeg)
```

- **EP01 노하우**: 원래 Veo 영상을 재사용했으나, EP02~05는 Veo 영상이 없음
- 대안: 키이미지를 정지 영상으로 만들고 페이드 인/아웃 적용
- 오디오는 0.5초 딜레이 후 시작 (자연스러운 호흡감)
- 영상 길이 = 오디오 길이 + 딜레이(0.5초) + 여유(0.5초)

### 3-3. 전환씬 (transition)
대사 없는 분위기 전환 씬.

```
키이미지 → 정지 영상 (3초) → 무음 + 페이드
```

- 기본 3초, `trim_to`로 조절 가능
- 페이드 인 0.5초 + 페이드 아웃 1.0초

## 4. 후처리 노하우

### 4-1. 정규화 + concat
모든 클립을 이어붙이기 전 정규화:
```
scale=1920:1080 (패딩), yuv420p, libx264 crf18, aac 192k 44100Hz stereo
```
→ concat demuxer로 무손실 이어붙이기

### 4-2. EP01에서 배운 것
1. **VEED 영상 길이는 TTS에 맞춰짐** — 별도 트리밍 불필요
2. **내레이션씬 슬로모션**: Veo 영상이 TTS보다 짧을 때 `setpts`로 슬로모션 적용 (최소 0.5배속)
3. **오디오 딜레이 0.5초**: 영상 시작 직후 바로 말하면 부자연스러움. 0.5초 여유가 자연스러움
4. **페이드 인/아웃**: 전환씬은 반드시 페이드. 하드컷은 어린이용에 부적합

## 5. 이미지 생성 노하우

### 5-1. 나노바나나프로 (Gemini 3 Pro Image)
- 캐릭터 레퍼런스 시트 + EP01 실제 씬 이미지를 **동시에** 참조로 넣으면 일관성 향상
- 프롬프트에 "MUST match the attached reference images EXACTLY" 포함
- 레퍼런스 시트만 넣으면 매번 다르게 나옴 → EP01 완성 이미지를 추가 레퍼런스로 활용

### 5-2. 무료 티어 주의
- `gemini-3-pro-image` 모델은 일일 요청 한도가 **프로젝트 단위**
- API 키를 바꿔도 같은 프로젝트면 할당량 공유
- 대량 생성 시 유료 결제 활성화 필수

## 6. 파일 구조

```
output/
├── EP01/
│   ├── refs/          ← 캐릭터 레퍼런스 이미지
│   ├── keyframes/     ← 씬 키이미지 (한글 이름)
│   ├── tts/           ← 캐릭터별 TTS wav
│   └── lipsync/       ← 최종 영상 (씬별 + 완성본)
├── EP02/ ~ EP05/      ← 동일 구조
└── _archive/          ← 실험/테스트 폴더
```

## 7. 실행 순서

```bash
# 환경변수
export GOOGLE_API_KEY="your-key"
export FAL_KEY="your-fal-key"

# 1. 이미지 생성 (이미 완료)
python generate_all_images.py --all
python regenerate_characters.py  # 캐릭터 일관성 보정

# 2. TTS 생성
python generate_episodes.py --batch --tts-only

# 3. 전체 영상 생성
python generate_episodes.py --batch

# 또는 에피소드별
python generate_episodes.py --ep 2 --all
python generate_episodes.py --ep 3 --all
```
