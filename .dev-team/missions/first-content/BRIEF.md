# BRIEF — first-content: 첫 콘텐츠 완성 (아이들이 좋아할 영상 + 자연스러운 음성)

## 목표 (데모 가능 기준)
애니메이터 스튜디오(scripts/animate-episode.ts)로 동물마을 90초 에피소드 1편을 실생성 →
대표 검수(음성 자연스러움·립싱크·아이 소구) 통과 → 수정 사이클 → 3편 발행(published HITL).
아이 화면 음성 22개(P1-9) 전량 생성·커밋 포함.

## 성공 기준 / Validation
- 대표가 1편을 보고 "아이가 좋아할 것"이라고 판단 (정성 게이트 — 최종 결정권 클라이언트)
- qc-report.json overall pass/warn (fail 항목 0 해소)
- 음성: 캐릭터 구분 가능 + 어른 목소리 아님 + 감정 표현 들림
```bash
npm run lint && npx tsc --noEmit && npm run smoke:limited-animation
```
